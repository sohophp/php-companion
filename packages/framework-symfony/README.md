# @php-companion/framework-symfony

Symfony 的静态框架事实组件。它从 PHP Controller 的 `$this->render('literal.html.twig', [...])` 提取模板变量、序列化 PHP 类型和 Controller 来源；也读取标准或 legacy `services.yaml`、标准 `<container><services>` XML，以及返回 `ContainerConfigurator` closure 或静态配置数组的 PHP 服务配置，提取显式 class、alias、public、autowire 与源码范围，并针对调用方提供的已索引 PHP class 展开确定性的 resource/exclude。YAML 值中的精确 `@service`/`@?service` 可定位、枚举全部引用范围，并提供只替换 ID 段的输入前缀；声明键、转义值、表达式、参数和损坏 YAML 保持未知。传统 XML 中明确标为服务的 `argument`、`property`、`bind`，以及 `alias`、`parent`、`decorates`、factory/configurator 的 `service` 属性同样输出精确服务 ID 范围和输入前缀，供 XML 服务补全以及跨 YAML/XML Definition 和 References 使用；声明 `id`、普通标量、参数表达式、DOCTYPE、未选择或非活动环境的 `<when>` 与损坏 XML 保持未知。PHP Configurator 支持官方命名空间或 import 写法，以及 defaults、set/class、alias、load/exclude、public/private、autowire、bind、具名 arg/args、call/property、listener tag、remove/get 和静态 import；直接 `$container->env() === 'literal'` 或字面量在左侧的严格相等守卫、由其组成的完整 `if/elseif/else` 与嵌套分支，以及数组返回格式的 `when@environment`，均按显式环境选择；非全等、复合或动态条件与动态数组键整体拒绝；变量重赋值、factory/fromCallable/parent、abstract/synthetic、位置 args 和动态值会撤销或抑制无法证明的事实。YAML/XML/PHP 的字面量 import 会输出精确静态导入事实，供调用方建立受限导入图。XML 同样支持 defaults、bind、具名 service argument、call、property、prototype/exclude 和 `kernel.event_listener`，并按显式环境合并无条件配置与精确 `<when env="…">`；拒绝 DOCTYPE、动态环境、动态参数、abstract 与无法证明 class 的 factory。组件识别 `#[Autowire(service: '...')]` 字面量位置，为公开服务生成 PSR/Symfony Container 字面量 `get()` 返回事实，并解析已注册、启用 autowire 的服务构造参数与公开 `#[Required]` 方法参数、具名对象类型属性。选择顺序覆盖字面量 `#[Target]` 具名别名、匹配类型/参数名的 defaults bind/服务 bind/arguments、参数名具名别名、同名 service/alias，以及 resource 中唯一可赋值实现；绑定到非服务值时明确抑制。可完整解析的扁平对象 Union/Intersection 会按 Symfony 的类型排序和组合别名规则处理，只有组合别名存在，或每个成员都落到同一服务时才返回结果。PHP 8.2 DNF 只接受规范化完整 service/具名 alias，并验证实现满足至少一个完整交集分支；不做叶子级回退。Required 方法属性可沿已证明的非私有原型链继承；Required 成员位于抽象基类时，只有已注册具体子类都收敛到同一结果才返回；显式或无法静态解析的配置 `calls`/`properties` 会抑制对应成员。

组件还可把 Symfony `debug:container --show-hidden --format=xml` 一类开发调试容器 XML 当作只读数据，提取 bundle/编译器生成服务、别名、公开服务、`container.service_locator_context` 对应的可定位公开方法参数、直接构造参数和 `<call method>` 中的服务引用及参数位置，以及带 owner/property 名的直接 `<property>` 服务引用。调用方负责确认缓存新鲜度；解析器拒绝 DOCTYPE，不读取标量参数值，也不启动 Symfony Kernel、执行 Composer autoloader 或项目 PHP。errored 服务引用、嵌套集合、无法解析到 service class 的目标、factory、参数化 YAML class、复杂 glob、动态 Target/bind、非公开或复合类型 Required 属性，以及不能映射到明确 callable 和参数名的 locator 保持未知。

事件关系以精确来源范围输出：完整字面量或确定性局部构造的 `EventSubscriberInterface::getSubscribedEvents()`、类/方法级 `#[AsEventListener]`，以及 YAML 服务、确定性 resource 或新鲜 debug-container XML 上的显式 `kernel.event_listener` 标签，都可关联到已证明的公开非静态监听方法。订阅数组支持完整 `if/elseif/else` 的精确收敛：每个分支必须返回文本相同的静态 map，或向同一局部 map 追加文本相同的静态条目，并保留每个分支的来源范围。非收敛条件分支仅在基础事件键与追加键都是不重叠的字符串字面量、条件只含白名单环境检查且分支只能追加静态条目时保留基础订阅；可选条目不发布。继承或 Trait 组合的 subscriber map 支持由调用方证明宿主的 `self/static/parent` 类常量事件键；缺失绑定保持未知。Attribute 支持字面量事件、`Event::class`、首个原生对象参数推断、整数优先级、类级方法派生与 `__invoke` 回退。派发候选支持直接 `new Event()`、同一代码块内未经暴露或重赋值的直接构造局部变量及其有界直接别名链，以及每个分支都只向同一变量构造同一事件类的完整 `if/elseif/else`；显式字符串/类名/类常量事件名与命名参数同样受支持。调用方仍须以语义类型证明接收者属于 Symfony EventDispatcher 接口族。参数、部分或分歧分支、引用/复合别名、动态参数、辅助调用订阅数组，以及缺少明确 event/method 的编译标签保持未知。

当前只接受字面量模板名和字面量关联数组。参数、`$this`、`new` 与标量/null/数组字面量可确定类型；每个关联数组值还提供精确源码范围，供 SoPHP 语义工作区推断局部变量与调用返回值。动态模板或动态 context 不猜测。多个 Controller 的同模板结果由 interop 合并器保留来源与 Union。
