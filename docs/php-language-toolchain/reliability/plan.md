# 索引、引用与移动的一致性实施

范围：同一 Composer 项目内的单文件 PHP 移动、按文件增量索引、已证明符号的引用查询。复用现有倒排索引、依赖图与持久语义缓存，组件保留在 monorepo。

## 交付门槛

- 文档打开时编辑器内容优先；异步磁盘读取不能覆盖较新的打开文档。
- 文件新增、修改、删除采用合并增量队列，扫描中的事件在宣布完成前处理。
- 索引日志包含触发原因、耗时、文件数和缓存命中。取消与索引不完整不能作为零引用成功返回。
- 移动的 namespace 范围来自语法树；编辑使用源快照检查；保留未保存状态。
- 完整流程验证移动、引用、撤销、重做和缓存重启。禁止用零结果或单项测试代替完整验收。

## 性能目标

当前文件跳转 200 ms、项目跳转 500 ms、热引用 1 s 为目标而非已测结果。Winstar 文件数及真实性能需独立记录；隔离测试不等同于 Windows WSL 人工验收。

## 顺序

1. 日志与队列；2. 内容缓存与增量；3. 查询状态与引用；4. namespace 语法范围和移动事务；5. 自动化生命周期及候选包验证。
