# 一致性改进与实测（2026-09-16）

## 实现

- `@php-companion/index` 导出 PendingChanges，合并相同文件的事件，保留消费期间的新事件与失败重试。新增和删除不再触发全库重扫；Composer 图变化才要求重新发现项目。
- 完整索引补处理扫描期间的文件事件再结束；打开的文档覆盖磁盘和缓存，关闭后异步读取会再次检查是否已经重新打开。
- 缓存校验内容 SHA-256，而不只依赖大小和 mtime。统一语义事实序列化排序，避免嵌套成员访问等有效缓存被错误拒绝。
- Definition 按 PSR-4 精确加载；普通局部变量引用在文档内完成；已知类的引用与移动扫描项目源码的候选文件，只解析包含类名的文件。别名文件包含原始 import 名称，因此也会进入候选。动态字符串和间接框架注册不作为确定的普通 PHP 引用。
- 类候选缓存按文档和文件事件失效；成员级全项目查询仍保留完整索引门禁。查询记录耗时、范围和结果数，索引不完整或取消返回明确状态，不作为零引用成功。
- 移动使用语法树 namespace 名称范围和不可变原文快照；VS Code 应用前重新核对参与者内容。完整计划的 namespace/import 编辑与文件操作组成同一个撤销事务。校正不再强制保存脏文件。
- Explorer 超时或参与者变化后的降级路径仍可能报告无法完成并尝试恢复，不保证任意扩展干扰、批量目录移动、跨项目移动都能成功。
