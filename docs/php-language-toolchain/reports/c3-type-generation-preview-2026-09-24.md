# C3 类型生成预览与取消

日期：2026-09-24。

类型生成命令现在先用只读虚拟 PHP 文档展示将写入的完整源码，再用非模态通知确认。取消或关闭预览不会写文件；确认后重新检查目标文件，使用一个 `WorkspaceEdit.createFile` 创建内容，并打开结果。预览提供器随扩展释放，单次预览内容在关闭后清理。PSR-4 命名空间、目标 PHP 版本和类型名称仍使用原有规则。

定向验证通过：根扩展与测试 TypeScript 类型检查、所改文件 ESLint、隔离 VS Code 1.139.0 Linux x64 C3 宿主（退出码 0）。宿主在独立临时 Composer 项目中检查预览的命名空间和类声明、取消后没有文件、确认后文件内容，以及一次 Undo 删除生成文件；同一套件中的三条导入版本保护测试也通过。另一次宿主回归在确认预览期间由并发操作创建同名文件，SoPHP 保留了并发文件内容，没有覆盖它（退出码 0）。日志为 `/tmp/sophp-c3-generation-preview-final-20260924.log`、`/tmp/sophp-c3-generation-conflict-20260924.log`。

**开放项：** 同一宿主中，文件创建的 Undo 后一次 Redo 没有恢复文件；[最小资源编辑探针](c3-type-generation-undo-redo-probe-2026-09-24.md)也复现该行为。本次不将类型生成算作通过 C3 的 Undo/Redo 门槛。真实键盘点击、WSL Remote 与安装候选的可见体验仍需独立验收。

后续尝试把空插入或同值替换加入同一个创建编辑，作为已打开源文件上的撤销锚点；两个隔离宿主探针仍无法在一次 Redo 后恢复生成文件。这些探针代码没有进入产品，日志分别为 `/tmp/sophp-c3-anchor-probe-20260924.log` 和 `/tmp/sophp-c3-anchor-same-20260924.log`。
