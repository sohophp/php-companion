# C3 返回语句的 Extract Method

日期：2026-09-25。类方法中完整选中末尾的 `return`，或选中连续语句并以 `return` 结束时，SoPHP 现在可把这些语句提取为私有方法，并在原位置以 `return $this->extractedMethod(...);` 调用。新方法沿用原方法的原生返回类型；原方法未声明返回类型时，新方法也不声明。

输入仍受已有数据流证明约束：直接返回的局部变量或参数、已证明的按值调用实参可传给新方法；引用调用、赋值表达式、匿名函数、yield 和无法证明的输入保持拒绝。返回引用的方法也拒绝提取，避免改变引用身份。`return;` 与 `void`/`never` 返回类型不作为有值返回提取。

语义测试覆盖先调用再返回的语句序列、有类型直接返回、无类型直接返回和返回引用反例。当前 10 项 Open Source Pack 的 VS Code 1.139.0 源码宿主验证了 Code Action、预览取消、应用、返回类型、输入与语句顺序，以及两种返回形式各自的一次 Undo/Redo。日志 `/tmp/sophp-c3-extract-return-final-pack10-20260925.log`，退出码 0。语义包全量 392/392、构建、扩展测试 TypeScript 编译、相关 ESLint 与差异检查均通过。

此项扩展了 C3 的常用 Extract Method 语句范围；复杂控制流和多输出仍需独立实现。生成新文件的资源 Redo、安装候选与 WSL Remote 仍是开放门槛。
