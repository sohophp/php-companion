# C2 普通函数参数提示的候选索引

日期：2026-09-25。只修改 SoPHP 仓库，未修改业务项目、安装候选或打包 VSIX。

普通函数的 Signature Help 原先每次都遍历 `SemanticWorkspace` 中全部已解析文件，再查匹配的函数声明。现在按已维护的 `declaration:function:<fqcn>` 候选键找文件；索引暂时无法覆盖的文件仍由原有 `unindexedReferenceCandidateUris` 兜底。导入别名、完整限定名和同名不同命名空间仍按解析后的完整函数名匹配。

定向回归覆盖跨文件 `use function ... as ...`：打开使用方后，未保存地把提供方 `int $value` 改为 `string $text`，参数提示同步更新；再改掉提供方函数名，旧调用不再得到签名；另一个命名空间的同名函数不能冒充结果。语义测试 388/388、语义与 Language Server 类型检查、相关 ESLint，以及独立 Composer 根的真实 stdio 六项编辑查询定向测试均通过。

额外运行 3,002 个已解析文件的本机合成夹具，每组 300 次普通函数签名查询。索引路径中位约 0.014 ms、P95 约 0.029 ms；将候选函数在运行时临时改为返回全部文件、模拟原先全文件遍历，中位约 1.018 ms、P95 约 1.200 ms。该对照只衡量语义层查询，不能推断 VS Code 弹窗端到端时延；没有改动结果集的完整性要求。下一步继续从真实日常输入中的错误结果或可见等待选择 C2 缺口。
