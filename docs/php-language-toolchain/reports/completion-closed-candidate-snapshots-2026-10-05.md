# D72 候选关闭后的磁盘快照保护

日期：2026-10-05。前检查点 `d1bad3ca`，同一开发分支。本批处理已有冷类型加载缺口，不增加补全类别或设置。

## 复现与修改

把实际生产 bundle 的目标文件读取暂停在**已取得旧字节之后**：磁盘是类，候选缓冲区打开后磁盘被替换为同名接口，缓冲区关闭并完成磁盘恢复；最后释放旧读取。D70 产品的 PSR-4／PSR-0 在 PHP 7.2／8.5 配置中，旧请求和随后新查询都恢复成旧类 kind 7。classmap／files 在相同交错中原本已返回接口，不称为这次新修复的失败入口。

共享类型加载现在复用跨关闭保留的每文档 revision。读取期间发生文档生命周期变化时，最多重读一次；再次失效则拒绝旧快照。caller 的 await 之后同步重新选择当前缓冲区或已验证磁盘快照，选择到解析／更新间不新增异步等待。应用于 canonical 类型、非 PSR-4 类型及 classmap 命名空间加载；保留数量、文件大小、可加载路径和解析规则，不创建另一套索引或无界重试。

读取门控只修改自己启动的子进程；默认的读取前暂停保持，新增关闭反例使用读取后暂停并核对捕获原字节。没有改动用户项目或已安装扩展。
