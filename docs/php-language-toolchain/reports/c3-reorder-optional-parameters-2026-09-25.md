# C3 方法家族参数重排：默认参数

日期：2026-09-25。独立 Composer 测试输入；未修改业务项目，未生成 VSIX。

以前只要方法声明包含默认参数，重排计划就整体拒绝。现在要求所有家族成员有相同的必填/可选分界，且默认参数形成连续后缀；必填参数只在必填段内移动，可选参数只在可选段内移动。声明与 PHPDoc 的整个参数片段一起移动，各成员保留自己的默认值和参数名。

对调用方：全具名实参保持原样；混合实参只在目标固定或整个家族参数名一致时，将前面的位置实参补成具名实参；纯位置调用只在其已提供的参数集合经重排后仍是同一集合时按原安全条件换位。只传必填参数的调用不受可选段换位影响。会让部分位置实参绑定到另一个可选参数、跨必填/可选边界、家族默认边界不一致，或需要把纯位置调用改写为 PHP 8 具名语法的情况继续拒绝。
