# phpstorm-stubs：调用后对象绑定与原生继承类型

日期：2026-10-03。沿用已固定的 phpstorm-stubs 来源；本批修复 SoPHP 对已有签名与继承事实的消费，没有换来源版本、复制说明文本或执行上游声明。

## 修复

- Intl `datefmt_parse($formatter, $text)`：未传入的可选引用输出参数不会改变 `$formatter` 的绑定；实际传入引用参数仍撤回不可靠类型。
- DOM `new DOMXPath($document)`：已知构造函数按值接收对象时，保留 `$document` 的补全；动态或未知构造仍保守处理。
- SimpleXML：无独立泛型声明的子类可继承原生父类已有的迭代元素合同；没有泛型实参、缺失父类或冲突继承不猜测。递归遍历受预算限制。
- 必填参数未提供、重复命名参数与未知解包不被当作安全调用。完整语义回归曾发现五个旧场景误通过必填参数检查，已修正产品判断，保留原测试预期。
