# C3 方法参数重排：字面量数组实参

日期：2026-09-25。只修改 SoPHP 仓库，使用独立临时 Composer 项目验证；未修改业务项目，也未打包 VSIX。

纯位置调用的实参现在可以包含由标量字面量组成的短数组或嵌套数组，包括静态键值。重排仍要求方法家族及调用目标完整可证明，所有参与实参都不改变求值效果。数组元素含函数调用、变量解包、引用或其它无法证明无副作用的表达式时，整个重排计划继续拒绝。字面量检查共享最多 128 个节点的预算；超过预算保守拒绝。

语义正反例先证实此前对纯数组返回无计划，再验证 `['mode' => ['fast', 1]]` 与 `[true, null]` 可随参数顺序重排，而嵌套调用和数组解包仍拒绝。定向语义测试 6/6、Semantic TypeScript、相关 ESLint、测试 TypeScript 与差异检查通过。独立 VS Code 1.139.0 Linux C3 宿主验证了该调用的取消、应用和一次 Undo/Redo，退出码 0；日志 `/tmp/sophp-c3-literal-array-reorder-20260925.log`。

这不扩大到动态数组、带副作用的元素、未证明的变量或工作区外调用。生成文件资源操作的一次 Redo 仍未通过，C3 整体未完成。

同日补齐 PHP 7.2 常用的 `array(...)` 写法。解析器已将两种数组写法归入同一语法节点，但重排原先在外层调用的最后一个实参结尾查目标签名；最后实参是 `array(...)` 时，该位置落入内层数组，外层方法签名返回空。重排现在在第一个实参起点定位外层签名，再复用同一纯字面量检查。传统数组含嵌套调用或解包仍拒绝。定向语义测试 6/6、Semantic TypeScript、扩展测试 TypeScript、相关 ESLint 和差异检查通过；最终定位点的独立 C3 宿主同时验证短数组与 `array(...)` 的取消、应用和一次 Undo/Redo，退出码 0，日志 `/tmp/sophp-c3-legacy-array-first-argument-20260925.log`。该签名定位调整只应用于方法参数重排计划，不代表所有 Signature Help 场景已复核。
