# C3 类型生成预览关闭失败

日期：2026-09-25。类型生成在用户确认后原先没有检查 `vscode.window.tabGroups.close()` 的布尔结果；若 VS Code 拒绝关闭预览，命令仍可能创建目标 PHP 文件并留下预览标签。关闭预览抛错也会直接使命令失败，缺少明确的生成结果。

现在预览关闭返回 `false` 或抛错时，命令返回 `false`，显示本地化的失败提示，并且不创建目标文件。若预览标签仍打开，内容提供者保留该预览文本，直到标签真正关闭；正常确认、取消、并发目标创建与后续创建流程仍沿原路径运行。

独立 VS Code 1.139.0 Linux x64 C3 源码宿主 `/tmp/sophp-c3-preview-close-failure-20260925.log` 退出码 0。测试向生成命令分别注入关闭返回 `false` 与抛错，断言目标文件不存在，并在返回 `false` 时确认仍打开的预览可读；完整 C3 宿主其余操作继续通过。根扩展与测试 TypeScript、相关 ESLint 和差异检查通过。未修改业务项目，也未打包 VSIX。

此修复只收口预览关闭失败的结果与副作用；生成新文件的一次标准 Redo 仍未恢复，C3 该项门槛保持开放。安装候选及 WSL Remote 的弹窗可见性尚待验收。
