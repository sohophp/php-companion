# D67 已有分隔符前的命名空间接受

日期：2026-10-05。基线 `c0d44042`，同一开发分支。

## 复现与修改

在 `use RootImportName§space\Other;` 的词中接受 `RootImportNamespace\`，原编辑仅消费当前词，保留原有反斜杠，实际文本形成 `RootImportNamespace\\Other`。两配置版本、两索引模式的原输入均复现替换范围失败；保留原候选和实际接受文本。

语言服务器的类型命名空间与 function／const 导入命名空间两个编辑入口，现在仅对 Module 候选消费紧邻当前词的已有反斜杠，再插入一个反斜杠。光标置于分隔符之后，继续填写下一段；后续类型／符号、注释、逗号、分组花括号保持。无已有分隔符仍正常插入；普通类、函数、常量候选不采用该消费规则。沿用标准 LSP TextEdit，不增加设置或改变所有权。
