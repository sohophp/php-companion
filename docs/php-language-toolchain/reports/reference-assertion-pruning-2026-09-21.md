# References 精确语义阶段：排除无关断言调用

日期：2026-09-21。源码基线：`d6c0792`。

## 发现与改动

真实 Winstar `get()` 引用的精确语义阶段约 4 秒。CPU 采样显示成员解析重复检查静态工厂链、动态调用及 PHPDoc 断言。成员表达式不含 `::` 时跳过静态链正则；文件不含动态方法访问时跳过动态调用匹配；推断某变量的 PHPDoc 断言时，先排除参数和接收对象都未提及该变量的调用。接收对象检查覆盖类方法 `$this` 属性断言：初版筛选曾使两项现有测试失败，修正后 Semantic 285 项全部通过。

查询时临时建树虽占约 0.8 秒 CPU，但移除后 Winstar 精确语义阶段从 3.78 秒升到 8.27 秒，故保留。尝试异步压缩候选缓存、跨成员调用缓存成员列表均未显示稳定净收益，已撤回。
