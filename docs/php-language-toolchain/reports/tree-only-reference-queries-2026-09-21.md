# 首次 References：避免重复语义提取

日期：2026-09-21。优化前基线：`9ade253`；对照 VSIX 为 `artifacts/php-companion-alpha-0.4.5-76e99553/` 的核心扩展。

## 实现

`PhpSyntaxParser.parseTree(source, oldTree?)` 只创建 Tree-sitter 语法树，支持原有增量编辑；调用者负责 `tree.delete()`。完整 `parse()` 仍提取声明、作用域、类型与控制流事实，内部复用同一语法树入口。Semantic 中 23 处原先只读取 `parse(...).tree` 的查询改用新入口，避免在引用匹配、成员推断和相关语法检查时重新构造已有索引事实。查询的树保留与释放策略不变，候选文件范围不变。

完整解析还复用遍历时已知的父节点，将调用上下文的祖先查找改为每层只读取一次父节点。只有根节点报告语法错误时才逐节点提取错误；错误文件的恢复遍历仍保留。原始名称的排除范围按源码顺序单次推进，使用已遇到范围的最大结束位置处理重叠字符串、注释和 import，避免为每个单词重新扫描全部范围。
