## 环境和证据

从 WSL 发起原生 `node.exe`，在新建 NTFS 临时目录运行正常服务器和现有基准。12 个复制文件包含正常运行资源、基准、测试工具及私有启动脚本；复制摘要逐项匹配，三个阶段结束后再次核对通过。私有脚本设置阶段环境和正常命令参数，未修改服务器、基准查询、断言或计时。

六次服务器及三个基准驱动正常退出，标准错误为空。各阶段 `Win32_Process` 查询均无本批残留节点进程，最终独立查询再次为空，WSL 互操作进程亦已退出。临时项目、缓存及 NTFS 复制目录清理通过。2,087 个冻结产品输入保持，未覆盖此前冻结清单或修改日常 Profile。

## 验证边界

本批是 Windows 原生协议自动化，未执行真实 VS Code 窗口或真人 WSL 会话。Node v24.16.0 的证据不等于其它 Node 版本资格；其它 PHP 目标、macOS、真实复杂项目和多小时会话本批未执行。

工作集为每十次编辑的周期采样。最大采样值不代表真实峰值；结束减基线的负值不证明内存优化，也不代表垃圾回收后的保留内存。

复杂 Controller 的原性能预算失败记录保留，本批不作其达标结论。未重跑未变生产构建的完整 Semantic/LSP/编辑器资格；没有提交、推送、发布或更新 Profile。功能扩展继续暂缓，F13/P9/R4 与完整计划仍开放。
