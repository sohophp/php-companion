# C2：合并取值与 match 分支补全

日期：2026-10-02。对应补全路线图第二／三阶段的语法位置与预期类型排序。

## 修改与范围

原实现未把 `??` 和 `match` 取值分支提升到外层返回／赋值位置；同时 match 条件和标签可能误用外层实参合同。最初 13 个固定样例为九失败、四通过。

- 统一取值位置返回起点与是否允许 null，复用现有返回、参数、变量／属性赋值的类型证明与候选排序。
- `??` 两侧使用结果合同；左侧允许可空类型，不错误降级可空候选。右侧仍使用结果合同。
- match 取值分支使用外层合同，subject 与条件标签不借用该合同；内层调用仍使用自己的参数签名。
- 候选类型未知时不猜测，不删除其它变量；语义查询不修改项目文档或修订。对外协议和设置保持原有接口。
