# C2：按值调用的数组实参

日期：2026-10-01。源码增量；未打包、提交、推送或更新 Profile。

## 失败与实现

`$value = null ?: new Repo(); observe($value, []); $value->rea` 在唯一函数全部参数按值传递时仍没有成员建议。旧证明只允许直接变量和标量，空数组也使连续语句失效。新增回归先复现此失败，再修改语义层。

调用实参的语法检查现递归接受数组创建表达式，包括空数组、短／长语法、嵌套数组、静态键与直接变量键／值及注释；叶子仍仅接受直接变量或不插值的标量。共享每次调用 256 个值节点预算，深度沿用 16 层预算。目标唯一、全部形参非引用及局部未逃逸条件不变；不把数组语法可证明当作方法纯净或对象属性不变的证据。

数组中的引用、展开、赋值、调用、插值和成员读取都不放行，超预算同样返回未知。PHP 8.5 实际运行验证：`function valueOnly($options) { $options['ref'] = new Other(); }` 接收 `['ref' => &$value]` 后可以改变原局部对象的类，尽管函数形参不是引用。因此不能只根据形参无 `&` 就放行所有数组内容。
