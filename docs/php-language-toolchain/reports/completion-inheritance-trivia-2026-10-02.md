# 继承声明补全：注释与类型引用

2026-10-02。本轮限定为声明类型引用中的注释处理，不新增设置。

## 问题与修复

新增语义矩阵 22 项，修改前 18 失败、4 反例通过。`extends`／`implements` 和类型之间的注释使前缀判断失效，注释中的 `}` 与关键字也影响继承类别判断。

新增按 SemanticFile 身份缓存的补全文本视图：只把解析器已识别的注释内容替换为等长空格，保留 CR/LF 与 UTF-16 偏移。限定类型前缀、普通类型前缀、继承类别与 catch 类型判断共用该视图。编辑后的文件身份变化自然撤回旧视图。代码和字符串内容保持原样，非代码位置仍按原有边界保护。

类 extends 只返回类，类／枚举 implements 与接口 extends 返回接口；命名空间别名和多接口列表中的注释不影响引用。未闭合注释、字符串与 HTML 反例不产生候选。
