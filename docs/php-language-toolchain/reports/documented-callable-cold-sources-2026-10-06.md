## 源码修复

D153 的原定向测量在首次补全时返回空列表：PHPDoc 回调返回的 Row／Other 类分散在 Composer PSR-4 文件中，既有依赖收集只处理具名函数。本轮把稳定 PHPDoc 回调变量的返回注解接入同一个有界表达式依赖收集入口，条件两分支均收集可能来源。

来源与值证明保持分离。该入口复用既有参数／局部注解、稳定别名及作用域保护，过滤模板名、标量、数组形状键和条件参数名；真正的补全和返回判断继续由原语义事实决定。语义依赖查询本身不会增加工作区修订，也不会将未加载类型变为可补全成员。

反例又发现文档返回 int 被对象转换入口当成 App\int 类来源。对象转换现在拒绝原生标量及已知 PHPDoc 运行时基础类型，让它们不进入类加载。

按需索引下，外部父类的未保存修改原先仍显示旧 common 成员。已知类型来源刷新扩展到父类／接口／Trait 的现有层级来源检查，最多 64 个已知类型节点；每个打开 URI 本次只刷新一次，直接读取编辑器缓冲区，不增加磁盘扫描。未知或不完整层级仍沿原加载路径处理。
