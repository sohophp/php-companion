# C2：直接构造对象的按值方法调用

日期：2026-10-01。源码增量；未打包、提交、推送或更新 Profile。

## 复现与修复

普通非 final 类的 `$observer = new Observer(); $value = null ?: new Repo(); $observer->observe($value); $value->rea` 仍丢失补全，尽管实际接收对象及方法参数都可以确定。之前只接受 final 类、final 方法或 private 方法。

本轮额外证明直接构造的接收对象：最近赋值必须来自实际 `new`，与调用位于同一语句块，构造类与解析签名一致，现有局部类型证明在调用前仍然有效。参数类型、工厂返回和条件创建不能替代这个证明；`new static` 保留不确定性。唯一声明、参数非引用和调用重入预算保持原有约束。

检查接收对象的连续语句时，另一变量的字面量条件简写三元构造赋值曾中断证明。现接受无语法错误、条件为标量且分支均为标量或字面量实参构造的这一形式，仍要求局部变量未逃逸。没有放宽一般表达式、引用实参或对象属性稳定性。
