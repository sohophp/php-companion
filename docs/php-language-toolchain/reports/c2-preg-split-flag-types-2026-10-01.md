# C2 preg_split 标志位元素类型（2026-10-01）

## 修改

接续[字符串拆分列表类型](c2-string-split-list-types-2026-10-01.md)。内置 `preg_split` 原来始终返回 `list<string|array{0:string,1:int}>|false`，普通拆分的字符串元素与偏移捕获的二元数组混在一起。

按 [PHP 官方文档](https://www.php.net/manual/en/function.preg-split.php) 独立实现语义合同：可证明的整数 flags 未设置位 4 时返回 `list<string>|false`；设置后返回 `list<array{0:string,1:int}>|false`。无 flags 使用 0；未知、字符串转换、不安全整数或无法证明的表达式继续使用原联合类型，不删除失败分支。

声明签名与默认值核对固定 phpstorm-stubs 修订 `e4f5f6c3de39f3bab3e9f3fca4b8cdb8b061e681` 的 `pcre/pcre.php`。上游此处的 `string[]|false` 没有区分偏移捕获，所以不直接覆盖已有宽返回声明；使用官方文档和运行时补齐语义层。

标志位证明支持整数常量、导入别名、括号及 `|`、`&`、`^` 组合。使用 BigInt 避免 JavaScript 32 位按位运算截断；只接受可安全表达的整数，深度上限 16，备选组合上限 16。项目同名函数不走内置合同，项目同名常量按自身数值解释。

调用签名匹配此前不能识别整数按位表达式，导致合法组合不能进入返回推断；现在两个操作数可证明为整数时认定结果为 int。字符串位运算及未知操作数未误判为整数。`~`、跨函数动态 flags 和超出证明预算的输入仍保持保守，本轮不扩张成完整常量解释器。
