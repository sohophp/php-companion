日期：2026-09-23。Language Server 现在按 LSP 客户端界面语言，为抽象属性/方法、只读属性、Property Hook 与魔术方法签名的各项违规条件生成文案，再按原顺序组合。条件判断、诊断代码、严重性和范围未改；英文默认消息保持既有文本。
