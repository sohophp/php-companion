# C3 Rename 规划结束到预览建立之间的文件变化

日期：2026-09-25。只修改 SoPHP 仓库和独立测试夹具；未修改业务项目，也未打包 VSIX。

Safe Rename 原先在获得服务器编辑计划后建立磁盘基线和差异预览。若引用文件在计划返回后、预览建立前由外部进程改写，打开文档缓存仍可能是旧文本，旧计划会进入预览；应用前的现有校验只能较晚拒绝。直接 F2 Rename 使用的来源校验也只核对打开文档文本，未核对未修改文档对应的实际磁盘字节。

现在在 Rename 准备前记录源文档版本与磁盘摘要；收到计划后、建立预览前检查源文件和服务器返回的每个参与文件源码摘要。对于未修改的打开文档，同时读取磁盘校验，避免缓存旧文本掩盖外部改写。原有预览确认后的来源和磁盘复核继续保留。文件变化时命令返回 `false`，不展示旧预览，也不应用文件改名。

隔离 VS Code 1.139.0 C3 源码宿主在计划返回后改写未打开的 PHP 引用文件，确认 Rename 在预览前拒绝、改写内容保留、源文件及目标路径未变化；同一宿主的正常类型 Rename、预览、取消、应用和一次 Undo/Redo 仍通过，退出码 0。日志为 `/tmp/sophp-c3-rename-plan-preview-gap-20260925.log`。根扩展与测试 TypeScript、改动文件 ESLint、`git diff --check` 通过。

此门禁覆盖一条确定性的关闭文件改写路径。未保存关联文件与真实 Explorer 时序、安装候选和 WSL Remote 仍需单独验收；生成新文件的一次 Redo 是独立开放项。
