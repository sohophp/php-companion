# D83 控制流中的变量补全

## 修复范围

`if ($value !== null)` 的分支内，候选说明和排序仍使用入口的 nullable 类型。类型谓词和精确布尔判断也没有进入同一补全读者；排序能把当前已证明的值放在不兼容的位置。

补全现在复用已有 `applyDirectFlowNarrowings`：只取当前词法作用域／范围、通过稳定性核验且没有后续赋值的事实。支持已证明的非空、早返回、内建类型谓词、精确布尔值与 `instanceof`。无法证明入口值时，只有合法的正向判断可提供具体类型；同名业务函数不作为内建谓词。原深度预算保留，没有新配置、缓存或 Provider。

参数按引用传递或经过已知引用修改后，不再用旧声明证明当前值。未知调用也会撤回相关收窄与入口值证据；同时检查位置／命名参数。重新赋值使用 D82 的当前值，离开分支不保留分支内的判断。动态引用与全部控制流仍不作为已完成范围。
