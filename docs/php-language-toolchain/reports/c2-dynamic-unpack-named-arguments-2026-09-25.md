# C2 动态实参展开后的参数提示

日期：2026-09-25。只修改 SoPHP 源码和独立测试；未修改 Winstar 代码，未打包 VSIX。

[PHP 手册](https://www.php.net/manual/en/functions.arguments.php)说明 PHP 8.1 起可在实参展开后指定命名参数，但不能覆盖已展开的实参。对 `configure(...$args, ho`，`$args` 可能展开零个、多个位置参数，也可能含名称；旧实现却把整个 `...$args` 当成恰好一个位置参数，错误地标记 `$host` 已占用并隐藏 `host:` 建议。

语义层现在不把展开片段计为一个确定的位置实参。对于动态展开，命名参数补全不再猜测哪些名称可用；如果当前尚未写出完整命名参数，LSP 不返回会让 VS Code 默认高亮第 0 个参数的签名浮层。若当前已明确输入 `tls:`，参数位置仍可精确高亮 `$tls`。已知为空的 `...[]` 不占用任何参数，继续提供正常补全。其它静态展开数组的精确占用推断尚未实现，暂按不确定处理。

验证：红绿语义回归复现旧的 `usedParameterNames: ['host']` 后，完整语义包 390 项通过；真实 stdio LSP 覆盖动态展开、明确命名参数与空展开；隔离 VS Code 1.139.0 C2 源码宿主验证无误导浮层或命名建议，退出码 0，日志 `/tmp/sophp-c2-unpacked-named-safe-20260925.log`。本次还观察到：若 LSP 仅省略 `activeParameter`，VS Code 会默认显示第 0 个参数，因此最终实现选择在位置无法证明时暂不显示该浮层。安装候选与 WSL Remote 仍未据此验收。
