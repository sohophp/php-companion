# C3 Rename 与 Extract 应用前预览复核

日期：2026-09-26。只修改 SoPHP 扩展和独立 VS Code C3 夹具；未修改业务项目，也未打包 VSIX。

Rename 与 Extract 原先在用户确认后检查一次预览标签，然后异步核对相关文件的当前内容。若这段等待期间关闭预览，旧检查仍允许编辑应用。现在在最后一次源码与磁盘核对后、`WorkspaceEdit` 应用前再次确认所有预览标签仍然打开；关闭任一差异标签即取消本次操作。提示文案也改为“应用前关闭”，覆盖确认前和确认后的情况。

隔离宿主新增两个负例：多文件 Extract 和 Rename 均在确认后、应用前关闭预览，命令返回 `false`，所有参与文件保持原样。原有正常应用、预览取消、并发改动与一次 Undo/Redo 随完整 C3 套件通过。功能逻辑调整后的 VS Code 1.139.1 Linux x64 源码隔离宿主退出码 0，日志为 `/tmp/sophp-c3-preview-final-rerun-20260926.log`。此后只修正中英文提示文案；文案改动通过扩展与宿主 TypeScript、相关 ESLint、差异检查，未再运行宿主。

本结果仅证明本地源码宿主的已测路径。当前私有 `15a5254` VSIX 不含本次增量；真实 WSL Remote、跨平台和长时间使用仍需后续候选验收。
