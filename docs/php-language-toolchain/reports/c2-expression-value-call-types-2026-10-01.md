## 复现与实现

唯一按值函数或精确构造对象的方法接收 `FLAG`、`Type::FLAGS` 等常见参数时，后续局部成员补全仍失效。新增回归先复现裸常量失败，再扩展既有调用实参语法证明。

现在统一识别普通／限定／namespace 相对常量、常量与类型 import alias、静态类常量与枚举 case，以及括号、单目、二元和完整／简写条件表达式。每个操作数及分支递归经过相同检查，数组键／值也复用此路径，因此 flags 位运算和嵌套选项不必单独补丁。256 个节点、16 层深度预算不变。

显式函数调用、写入、增减、展开、引用、动态类表达式和对象成员读取继续失败。唯一调用目标、全部形参按值及未逃逸局部绑定的要求不变；这是绑定类型证明，不是方法纯净性、常量值推断或对象属性稳定性证明。静态常量读取可能触发类装入，本轮不宣称其没有任何副作用，也不绕过已有局部逃逸检查。
