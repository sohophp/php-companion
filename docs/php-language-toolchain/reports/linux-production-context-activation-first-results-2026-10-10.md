## 计时起点与范围

隔离开发扩展的 `main` 指向一个私有观察器；观察器在调用原正常 `activate` 前读取 `performance.now()`，原激活 Promise 完成后立即打开消费者文档并发起第一次公开 VS Code 查询，向宿主返回原 Promise 与 API。观察器把宿主 Test context 显式代理为 Production context，使正常代码采用实际生产分支，保留各轮输入模式与代理模式；服务器日志核对没有 test-mode 标记。原正常扩展和语言服务器 bundle 均逐字复用。

每轮只执行一次初始 Completion、Hover、Definition，没有查询预热、轮询结果重试或强制 GC。Completion 校验首项名称、种类、完整方法签名、Snippet 及替换范围；Hover 校验最后一个生成类的变量类型；Definition 校验目标 URI 和精确方法位置。该计时包含原激活、文档打开及首次查询等待，与此前首个修改后 Hover、生产服务器启动观察器计时的起点不同。
