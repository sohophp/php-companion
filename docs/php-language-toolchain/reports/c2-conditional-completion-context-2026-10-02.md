# C2：条件位置与值分支的补全类型

日期：2026-10-02。R28；通用补全上下文增量，未打包、提交或更新 Profile。

## 缺口与修改

普通三元条件里的变量可能继承整个调用参数或返回值的类型，导致按无关合同排序；返回及赋值的值分支又因原正则只识别紧邻表达式而失去预期类型。

增加内部 `completionValuePosition`，以当前 CST 判断光标是否属于条件，或通过括号／三元值分支找到外层值起点。普通三元的条件不使用外层结果合同，保留默认匹配排序；值分支复用既有返回、参数和赋值类型。简写 `?:` 的左侧同时提供真分支值，因此保留其结果合同。遇嵌套调用的 arguments 停止向外查找，继续使用内层参数签名。

遍历最多 256 层，不发布恢复语法树或新增持久缓存。没有将 PHP 条件强制解释为 bool，没有过滤其它可见变量。
