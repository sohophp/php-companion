# D153 PHPDoc 回调的条件返回类型

## 修复范围

只有 `callable(bool $flag): ($flag is true ? ReadyResult : OtherResult)` 文档时，输入 `1` 原先被确定地投影到 `OtherResult`。实际回调可以有原生 bool 参数，也可以保持原值；只有文档不能证明是哪种运行时边界。这会让补全错误地显示一个分支的专有成员。

本轮保留已有 PHPDoc 弱标量输入兼容规则。输入本来与文档类型不兼容、但被该规则允许时，条件判断保留原输入和文档类型的可能性；明确的 `true`／`false` 仍给出精确返回。歧义返回只建议共同成员，已知对象输入及严格模式矛盾输入仍被拒绝。普通原生闭包和无条件文档返回路径保持现有行为。

联合类型的条件细化逐分支复用已有逻辑，同一参数的嵌套条件不再产生互相矛盾的分支。相同变量传给两个参数时，各参数可能有不同原生边界，不能强行关联其转换结果。缓存派生引擎 v77 → v78，避免复用旧结果；Core 的 Provider 所有权不变。
