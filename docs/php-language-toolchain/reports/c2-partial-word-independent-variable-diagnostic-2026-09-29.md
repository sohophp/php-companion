# C2 未完成单词旁的独立变量诊断

日期：2026-09-29。源码基线为 `32e7e6a` 加当前未提交增量；本批只改通用 SoPHP 语义与语言服务器，以及回归测试。未修改 Winstar 或其它业务项目。

## 问题与边界

在文件前部独立一行输入 `func` 等未完成单词时，PHP parser 会给该单词一个局部语法错误。原实现只要文件有任意语法错误，就撤下全部变量诊断；因此后面清楚可见的 `new Bootstrap(projectDir: $a)` 不再提示 `$a`。无语法错误时，当前源码原本已经会提示该顶层变量。

现在仅当**每个语法错误都是独立一行的单个标识符**时，语义层继续分析其它已解析语句中的变量引用。语言服务器只对这条可证明路径保留变量诊断，其他语义诊断仍按原规则抑制。不完整函数声明等可能影响变量定义的语法错误继续撤下变量诊断。文件顶层诊断仍使用 `php.variable.possiblyUndefined`，因为顶层 PHP 文件可能由外部作用域包含。
