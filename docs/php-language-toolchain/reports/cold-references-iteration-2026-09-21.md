# 首次 References：缩短验证循环并收窄热点

日期：2026-09-21。对照源码基线：`1a968af`。

## 改动

保留语法树时，成员目标解析从包含引用的语句起点读取源码，并将链式调用的参数偏移还原为文件绝对位置。语法树缺失或存在错误时继续使用完整前缀。新增测试比较保留语法树与重新构建的 Definition/References 结果，包括跨语句和多行链式调用。

候选语法准备的工作线程上限从 4 提高到 8，仍受 `availableParallelism()` 限制。试验过相邻批次的预解析与当前批次提交重叠：单轮首次查询仅从 14.833 秒到 14.563 秒、候选阶段从 10.629 到 10.592 秒；这部分已撤回。12 个线程相对 8 个也无可辨认收益，保留 8 个。验证内循环只运行受影响包构建、测试和一条真实查询；不在每次调参后运行全套发布检查。

## 同机串行对照

## 验证与限制

Semantic 285 项、Index 31 项、Language Server 200 项、受影响包构建及改动文件 ESLint 均通过；真实项目引用位置一致。首次 References 仍约 13–14 秒，Reload 首次仍约 8 秒，不满足流畅交互目标。8 个工作线程会增加冷查询时的并行内存占用，低并行度主机仍由系统可用并行度限制。后续继续针对约 9–10 秒的候选阶段以及约 4 秒的精确语义阶段定位热点；在这两个阶段取得明显改进前，不冻结新的 Alpha 安装包。
