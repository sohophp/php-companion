# 自有显示进程启动身份守卫（2026-10-10）

10k/50k 激活矩阵在 PHP7.3/onDemand、10k 第四轮因显示测量器身份检查退出。此前 PHP7.2 三模式两规模各五轮通过；本次共执行 34 轮，102 次首次公开查询全部正确，但第四轮显示进程清理身份失败，整个预定 270 轮矩阵未取得资格。原结果、失败与显示记录保留，未把它改写为产品查询失败或整轮通过。

原测量器在创建 Xvfb 后立即固定 `/proc/PID/cmdline` 摘要，该轮记录为零字节的 SHA-256。独立认证和编辑器查询完成后，严格清理守卫读到真实命令行，与初始空摘要不符而拒绝终止；原显示记录因异常仍为 running。联合终态重新核对确认实际相关进程已退出，仅有该自有 PID 的残留 X lock；核对 lock 所有者、PID、进程死亡及 socket 不存在后清理，原失败文件保持不变。

[显示测量器](../../../scripts/benchmark-editor-activation/owned-display.py)现在在原五秒启动窗口内等待非空且精确匹配的 argv，核对实际 executable 与进程启动 tick，随后才验证独立认证并启动测量子进程。终止前再次检查同一身份；不符时保存实际 PID、失败和认证目录，保留清理守卫。原激活时钟、首次查询、预算和正常八运行资产未修改。

实际 Xvfb/xauth/xset 控制确定性注入一次初始空读取：原脚本稳定重现红灯，新脚本通过；另注入清理时身份不符，新脚本仍拒绝终止并保留进程及认证目录，独立测试持有直接创建的 Popen 句柄，核对真实身份后回收其自有资源。[公开验证器](../../../scripts/benchmark-editor-activation/verify-owned-display.py)及[用法](../../../scripts/benchmark-editor-activation/README.md)已提供，两项公开控制也通过。五项控制、实际退出、Python 语法和正常八资产保持均核对，27 个修复/控制文件与前置 1,082 个失败文件归档绑定见[同名 JSON](display-startup-identity-guard-2026-10-10.json)。

修复后的编辑器大规模矩阵尚待执行。此前九版本×三模式的 1k 五轮和本次完成的 PHP7.2 大规模观测保持独立历史范围；完整规模/版本/模式、Profile/平台/长期/真人与原全部目标继续。日常 Profile 未更新，全部资格与全部目标完成均为 false。
