## 输入和执行范围

PHP 7.2、7.3、7.4、8.0、8.1、8.2、8.3、8.4、8.5 九个语义目标 × progressive/onDemand/experimental 三模式，各 50 次预热和 500 次正式编辑，共 13,500 次正式编辑、1,350 次预热。全部按原顺序串行执行，无失败、跳过或追加同一阶段。

progressive/onDemand 使用 PSR-4 和 500 个噪声函数，experimental 沿用 legacy 布局及零噪声函数。PHP 7.x 使用位置实参，PHP 8.x 保持此前命名实参输入；输入和默认行为依据[Linux 同工具报告](php-version-editing-recovery-2026-10-13.md)。各组的 Windows 命令、环境和资源摘要分别留存。

## 未执行和边界

PHP 版本是服务器语义目标，本批未执行实际 PHP CLI。Windows 原生协议自动化不代表真实 VS Code 窗口或真人 WSL 操作；Node v24.16.0 证据不覆盖其它 Node 版本。macOS、真实复杂项目、多小时会话本批未执行。

工作集为周期采样，采样最大值不是实际高水位，结束差值不是垃圾回收后的保留内存；负差值不证明内存优化。复杂 Controller 原预算失败保持独立。本报告不关闭全语法/API、完整 F13/P9/R4 或整个计划。

生产与基准本批均未修改；未重跑其原完整 Semantic/LSP/编辑器资格，未提交、推送、发布或更新 Profile。功能扩展继续暂缓。
