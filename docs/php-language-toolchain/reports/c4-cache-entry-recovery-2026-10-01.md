# 索引缓存元数据损坏恢复

日期：2026-10-01。对应 C4 缓存损坏、版本迁移与重启一致性要求的源码子项。

## 修改

索引缓存入口原来只检查包装 schema、version 和 root，随后直接接受 entries。现在检查 entries 必须为对象而非数组；每条记录的 size 为非负安全整数，mtimeMs 与可选 ctimeMs 为有限数，hash 为小写 SHA-256 十六进制格式。拒绝的条目单独从源码重建并输出既有失败说明，完整条目继续复用。仍兼容没有 ctimeMs 的旧记录；它们按既有时间戳逻辑保守重建。payload 继续交由原有语义恢复校验，不把元数据检查当成内容校验。

未更改缓存 schema、产品设置或版本迁移策略：不支持的 schema 或版本从当前源码重建，再次启动可以复用新缓存。
