# C1：解构赋值后的变量补全

日期：2026-09-26。仅修改 SoPHP 解析器、隔离测试及使用说明；未修改业务项目，未打包 VSIX。

关闭 PHP 通用词建议后，短数组解构 `[$first, $second] = $tuple` 和旧式 `list($first, $second) = $tuple` 的绑定变量没有进入 SoPHP 的局部变量候选。解析器过去只把左侧为单个变量的赋值记录为赋值事实。

现在解析器从解构左侧提取直接变量、嵌套列表和引用绑定，记录在所属作用域；只在整条赋值表达式结束后提供这些候选。键表达式不当作新变量，属性或数组元素接收者也不伪装成变量绑定。本次只补充变量存在事实，不给解构元素推造类型；已有数组形状类型推断路径保持独立。

验证：parser 86/86、semantic 406/406；parser 与 semantic TypeScript、改动文件 ESLint 通过。完整 10 项 Open Source Pack 的 VS Code 1.139.1 Linux x64 C1 源码宿主退出码 0，实际建议列表核对了短数组解构和 `list()` 后的变量；嵌套解构、引用绑定及键表达式反例由解析器／语义测试覆盖。日志 `/tmp/sophp-pack10-c1-destructure-20260926.log`。

已安装 VSIX、真实 WSL Remote 与其它平台尚未验收。动态解构键、复杂接收者和更多 PHP 版本语法仍需独立输入验证。
