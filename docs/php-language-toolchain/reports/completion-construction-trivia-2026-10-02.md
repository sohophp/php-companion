# 构造补全：关键字与类名之间的注释

2026-10-02。状态：本轮源码、协议和 Linux 可见接受验证通过。

## 修复

普通 `new` 已过滤接口、Trait、枚举、抽象类型和不可访问构造函数。本次发现的是注释后候选缺失：修改前六项语义用例中五项失败。原始文本正则既漏掉构造角色，也拒绝补全前缀。

语义层统一取得构造位置、前缀和命名空间，利用解析器的注释范围跳过 trivia；类型补全和预期类型排序共用这些事实。服务器通过 constructKind 判断是否插入构造括号。保留 `instanceof` 的接口／抽象类引用以及现有构造可访问性过滤，不把注释里的 new 当真实关键字。
