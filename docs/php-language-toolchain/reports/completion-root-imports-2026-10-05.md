## 失败及修正证据

1. 原入口不提供根命名空间类型；初始新语义与协议用例证明缺口。
2. 首版边界正则使 6000 注释声明测试超时；改为一次边界核对，未放宽原测试超时。
3. 新协议暴露词中命名空间替换及 progressive 首次冷导入缺口；按当前词与明确路径修复。
4. 首次词中 UI 接受未达到预期文本；增加显式类型编辑范围后通过。初次日志未记录实际错误文本，不推断具体残留结果。
5. UI 明确拒绝跨行分组 CompletionItem 编辑范围；改为当前词的单行范围后全部 16 次接受通过。
6. 原协议以 `use Dom` 只能有 `Domain\` 为前提。新根类型候选 `DomainException` 合法；断言保留命名空间及其编辑范围，并增加全局类型、合法种类和无额外导入编辑检查。原失败与补验分别保留。

这些针对不同证据修复；没有重复测量到绿色、降低性能预算或将筛选测试记为完整门禁。
