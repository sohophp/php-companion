# 声明补全：Trait final 的缓存与增量一致性

## 已复现的缺口

- 缓存中的 Trait alias 缺少 final 字段仍被接受，子类构造函数限制丢失。
- `seed as final __construct` 改成 `seed as __construct` 被记为 implementation 变化，changedTypes 为空。
- 原生方法的 finalMethod 也没有进入类型声明表面，修改 final 同样漏掉声明失效。

新定向回归在修改前 **5 失败、3 通过**，失败日志 /tmp/sophp-trait-final-cache-before.log。

## 实现

Parser 为所有 Trait alias 明确输出 boolean final；语义缓存验证其字段类型。final / finalMethod 进入声明变更比较，触发受影响类型及依赖失效。

语义快照版本 **82 → 83**，来源声明快照 **1 → 2**，项目语义缓存引擎 **v65 → v66**，承载语义与声明的按需候选缓存 **v6 → v7**。旧格式一次性回退到源码解析，覆盖旧 parser 可能整个漏掉 final alias 的情况。外层压缩容器、框架事实及其它候选目录的版本保持各自协议；没有增加用户设置或清除用户文件。
