# C2：按值调用后的局部类型保留

日期：2026-10-01。源码增量；未打包、提交、推送或更新 Profile。

## 实现

`linearLocalValueType` 原先仅能跨过少量内置读取调用。现在复用按源码版本缓存的函数参数声明事实：唯一解析的函数目标，所有参数均非引用，实参为直接变量或不插值的字面量时，可以跨过独立调用或对另一个简单局部变量的调用结果赋值，保留被查询变量的类型。这是局部绑定不会被重写的证明，不把函数当成没有副作用。

复用并补强上一轮构造赋值的未逃逸检查：引用参数、引用捕获、显式引用、global/static、动态变量、include/eval、extract/parse_str（含导入别名）均排除；旧版字符串 assert 也排除。被查询变量若先传给未知或可能引用传参的调用，后续构造赋值也不能再按未逃逸变量处理。引用 variadic、unpack、动态调用、嵌套调用、赋值实参、闭包实参和插值字符串均不进入本次普通调用路径。

未知返回类型不会阻止“按值传参”这项独立声明事实；它仍不为调用结果制造返回类型。目标重复、声明改为引用或源码被移除时，按现有 sourceRevision 机制撤回证明。
