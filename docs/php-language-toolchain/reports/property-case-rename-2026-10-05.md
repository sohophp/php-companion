# D112 属性重命名与引用的大小写身份

日期：2026-10-05；基于 `d3991627`，继续 C3 安全 Rename，并对齐 C2 属性名称规则。

## 复现与修改

同一类合法声明 `$options` 与 `$Options` 时，普通属性 Rename 的成员族和引用位置可能合并两者；私有或 Trait 路径也可能因错误冲突判断拒绝合法改名。修改前，首组 35 项有 **34 项失败、1 项通过**。这可能修改另一属性及其使用，不能只改建议列表。

现在名称身份区分类型 owner 和成员名：owner 沿已有类名大小写规则，属性名称精确匹配；普通／静态／私有／提升／Trait 属性的族、冲突、可证明动态名称和扫描均保持该身份。现有 method 名称规则保留。通用成员 References 也按种类匹配名称和身份，类常量及 Enum case 保留大小写，方法仍忽略大小写。原动态 unknown、完整继承、源码哈希与项目扫描拒绝门槛继续保留，没有新增设置或缓存格式。
