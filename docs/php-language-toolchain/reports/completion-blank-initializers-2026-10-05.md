# D77 空初始化值位置的补全

## 缺口与修复

现有 D44／D46 已处理默认值与常量表达式的版本规则。本轮补齐输入 `= |`、尚未写任何值时的位置识别：参数、属性、全局／类常量、枚举 case 和静态局部变量的 ERROR 树可能完全没有值节点，原入口返回未知位置，关键字候选也因空前缀被撤回。

沿用既有恢复预算：文档不超过 131072 字符、前向上下文最多 160 字符、祖先最多 256 步。仅当光标前是等号与空白／完整注释时，用占位值解析临时树，由 AST 证明初始化位置；普通赋值、比较、增强赋值、注释内光标均不据文本猜成声明默认值。文件末尾的未闭合函数参数列表另用临时闭合签名验证，绝不写回源码或发布临时语义事实。超过预算仍返回未知；复杂未闭合组合继续开放。

服务器在已证明的空初始化位置提供合法表达式关键字，沿用 PHP 版本的 `new`／静态闭包规则。在空前缀下不枚举所有 PHP 8.5 callable 引用；开始输入函数前缀后仍保留既有第一类 callable 插入。其它普通表达式和声明入口保持各自规则。此项没有扩大类型排序承诺：空值处原生声明类型的完整推断与排序、所有初始化表达式的类型正确性仍需独立检查。
