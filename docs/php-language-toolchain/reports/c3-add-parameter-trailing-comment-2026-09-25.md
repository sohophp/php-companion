# 新增参数识别尾部注释中的逗号

日期：2026-09-25。仅修改 SoPHP 语义层、测试与文档；未修改业务项目，未打包 VSIX。

## 问题与修复

公共方法家族及私有方法的新增参数操作，原来用字符串包含判断尾部是否有逗号。因此参数或实参后的块注释只要包含逗号，操作就错误地返回空计划。现在只把注释和字符串之外的逗号视为语法分隔符；私有声明头部的分号判断也采用相同规则。真正的尾随逗号仍拒绝，避免生成重复分隔符。
