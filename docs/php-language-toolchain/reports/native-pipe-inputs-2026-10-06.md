# D147：PHP 8.5 管道的原生参数转换

## 发现与修复

PHP 8.5 `|>` 原来把非数字字符串等弱标量全部当成兼容 int／float，且 `42.` 不能取得标量事实。正式源码复用现有原生转换，保留浮点语法与最新局部赋值；每个阶段分别检查真实原生参数及其类型契约。原生输入不匹配时撤回旧成员建议，合法新输入恢复。

类型事实沿管道传递，支持函数、静态方法、实例方法、箭头函数和匿名函数。未知动态回调、引用参数、发生未知修改或不兼容阶段不猜测。已知 string 在调用正常返回时转换为 int 的事实，与完全无类型输入分别验证；不把类型推断写成调用必然成功。

引擎 v74 拒绝旧派生缓存身份，持久化 schema 89／7／13 保持。绑定 `667108d4106f50f62dd0289dfabf5fc01807d26affebc38f079cab5ffd721ecd`、语义源码 `e82b33a1a321b4472dc7d33dae4302a25b9d05fed6b6e5475a6407dc4ca3d189` 和父提交 `c4f59fba` 的本批改动。
