# 解析事实缓存原型与默认模式恢复验证（D202–D213）

## 身份与结论

基于 `8518d44a`，正式 Core 仍为 `6cf4d4c8892342f04cd3ee1d7bea8351b38b2754564ea8edb183c03137c6a26a`。本批试验了私有解析事实缓存的一次编码、独立解码方案；收益不足且一个原合格对照超限，已撤回。八份生产 JS／WASM 与试验前逐字节相同，没有保留产品源码修改。

保留的修改是现有解析缓存隔离断言和连续编辑基准工具：工具可显式选择 `onDemand`，另提供符合 Composer PSR-4 的夹具布局，验证实际损坏缓存重写及未保存引用恢复。默认工具入口继续使用原 `experimental`／两文件布局。机器为 Linux x64／Intel Xeon E5-2696 v3，Node v22.14.0。原始运行摘要、哈希和 117 份已核对的本地归档见 [JSON 报告](parser-cache-trial-and-on-demand-recovery-2026-10-07.json)。

## 缓存试验：撤回

D201 诊断定位到事实复制成本。D202 先按当前 Composer 和源码取得普通基线，D204 再测序列化原型；五组各 100 次未保存修改后立即补全，包含首查询，首位及共享候选断言全部通过。两轮外部文件、Composer、Node 完全相同，各轮冻结输入、HEAD 和工作树保持；没有 profiler、testMode 或强制 GC。

| 场景 | 原版 P50／P95／最大 ms | 原型 P50／P95／最大 ms |
| --- | ---: | ---: |
| 固定 242801 字节，PHP 7.2 | 113.45／144.43／246.75 | 116.12／155.95／230.74 |

| 真实 Blog Controller | 50.63／69.60／148.72 | 53.97／73.47／176.57 |

大 Controller 仍超过原 150 ms 预算，PHP 7.2 对照由合格变为超限，Blog 的 P95／最大值也增加。单次成对测量不足以证明普遍收益，因此撤回原型 `016285fb`，不重复等价测量挑选通过结果。三点外部 RSS 采样保留在 JSON，不称作峰值或 retained heap。真实项目文件始终只读。

原型及恢复原版后的解析器完整测试均为 7 文件／158 项通过；类型检查和构建通过。既有隔离测试增加了对缓存命中结果的嵌套参数、属性标记和作用域参数的修改，再次读取须严格等于原始事实，包括显式 undefined 字段。原型补丁与构建已归档。

## 默认模式连续编辑与恢复

D211 正式运行 PHP 8.5／onDemand，100 次预热加 1000 次正式编辑，500 个干扰函数，50.410 秒退出 0。4880 份冻结输入、Node、HEAD、工作树及 Core 身份保持。四文件夹具分别包含 Alpha、Beta、噪声函数和编辑文档；类路径符合 PSR-4，函数文件声明为 Composer files。每轮六类查询，共 6600 次，另有冷引用、噪声加载、取消和重启检查。

诊断必须对应当前版本，成员排除旧类型，实参／成员排序及跳转 URI／起始位置沿用原断言。两条取消查询的未取消对照分别返回 100／59 个符号，实际取消耗时 9.65／1.64 ms，均低于原 100 ms 门槛。

直接 PSR-4 补全不需要持久索引。测试通过正常 references 查询填充候选缓存，核对当前未保存成员的唯一精确引用；关闭后破坏有项目条目的实际缓存，再启动新进程，重放与磁盘 Alpha 不同的 Beta 内容。补全、Hover、Definition、References 全部恢复；关闭后读取同一损坏文件，验证 schema、版本、根路径与非空条目均已重建。onDemand 不发出 eager 索引的损坏警告，报告明确记录 false；experimental 继续要求原警告。

RSS 共 112 次外部采样：基线 245.61 MiB、采样最大／结束 353.22 MiB、结束减基线 107.61 MiB，通过既有 128 MiB 差值门槛。这里不证明长期内存有界、真实峰值或 50k 缓存资格，也不与不同布局及引用工作的历史 experimental RSS 作直接对比。

- D205 在 onDemand 初始化等待不存在的全量索引完成消息，32.678 秒超时，没有计时资格。工具已按模式修正生命周期。

- D209 对正式 Core 拦截两条取消通知，100 次／零预热，19.041 秒。两查询均自然完成，子基准按预期退出 1，证明取消门槛没有把自然完成当通过。缓存及未保存恢复检查仍通过，两个 proxy／Core 进程对均已退出；其 RSS 属于 proxy，不作性能资格。

最终工具与测试 ESLint 通过。D205／D207／D208／D210 的历史工具源码已按原冻结 SHA-256 恢复保存；D211／D209／D212 的最终工具源码哈希相同。没有覆盖原失败或转移旧平台资格。
