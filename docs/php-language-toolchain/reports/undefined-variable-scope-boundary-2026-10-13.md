## 触发与修改

```php
$callback = (fn() => $missing) ?? null;
```

旧实现把外层 `??` 的安全读取条件应用到了箭头函数内部，因此漏报 `$missing`。普通闭包及外层 `empty` 同样可复现。树节点的 `parent` 访问每次创建新的 JavaScript 包装对象，原 `current !== scopeNode` 不能识别同一作用域节点；依赖源码 `web-tree-sitter.js` 的父节点 getter 已核对。

`undefinedVariables` 中的祖先检查现在以语法节点 `id` 判断作用域边界。检查在当前函数边界停止，函数内部的 `??`、`empty`、`isset` 仍按原规则抑制安全读取；合法参数、捕获和箭头函数外部变量保持。其余判断条件、输出范围和诊断级别未改变。
