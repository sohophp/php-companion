# D151：PHPDoc 方法重载与返回候选一致性

## 修复范围

合法的 `@method` 重载原先在签名排序后，又被变量、链式或静态调用的旧路径退回第一条文档声明。`42.`、`42.0` 等浮点字面量还会丢失浮点来源，被当成整数。基于实际 `__call` 的 24 个语义对照有 16 个差异；扩展到实例、静态、动态名称、命名参数和 nullsafe 等 168 个消费场景，有 116 个差异。

当前实现：

- 排序使用已有标量事实，保留浮点词法来源。按联合实参的可能分支选择重载，最多展开 64 种组合；超过上限保留候选，不猜唯一分支。
- 完成调用后复用同一组选定签名和文档返回合同。确定实参选择对应返回；歧义或未知实参保留可能返回，并只补全共同成员；已知与所有文档不兼容的输入不退回第一项。
- 去掉变量与 source chain 中绕过选择的原始 PHPDoc 返回兜底。链式成员的补全与跳转复用表达式类型，歧义共同成员可跳到两处声明。
- 冷查询收集文档各分支的返回类来源，包含静态调用；来源加载不证明运行时返回该类。保留已证明的框架类字面量返回事实，并验证实参兼容性。
- 引擎缓存 v76 → v77，让旧派生结果失效。Core 继续拥有通用 PHP 语义；没有增加必配设置或改变 Provider 所有权。

依据为 [phpDocumentor `@method`](https://docs.phpdoc.org/guide/references/phpdoc/tags/method.html)和 [PHP overloading 手册](https://www.php.net/manual/en/language.oop5.overloading.php)。这里的重载是 PHPDoc 对 `__call`／`__callStatic` 的描述；文档参数不变成原生声明，也不获得原生弱转换或执行证明。已有原生方法仍优先。

## 失败与修正

失败输出均保留：

- 正式主语料首轮 1376 项中，36 个歧义链式跳转失败；补全已正确，跳转仍走单类型路径。接入表达式类型后该轮全部通过。

- 首轮完整语义 **22205／22206**，唯一失败是既有 Doctrine 类字面量返回事实被新链式路径跳过；恢复事实优先级后定向通过，随后完整回归通过。首轮输入保持一致，没有删用例或修改原断言。
- 原型准备曾因替换 loader 未匹配而实际读旧产品，该输出标为 wrong-loader，不作为候选证据。PHP 7.2 `-n` 缺少 JSON 扩展的输出准备失败已改用基础文本编码；另有一次错误工作目录使测试重写未执行。上述准备失误与真实产品失败分别保存。
