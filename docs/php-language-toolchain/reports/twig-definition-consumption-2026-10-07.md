## 最终行为

- 根变量优先使用所有 render 变量来源的精确范围；无变量来源的旧 metadata 保留 Controller fallback。
- Definition 要求语义模型证明是变量读取或实际成员／方法调用。字符串、注释、HTML、数组键、过滤器、测试名、函数名、具名参数和未知接收者不会误跳到同名 PHP 变量；局部 Twig 变量及其成员不会误用 Controller 类型。
- Controller 模板匹配复用 parser 的模板根、别名及覆盖排序。按工作区隔离命名空间，选择最具体的嵌套根；同一物理模板的多个逻辑来源合并，保留显式项目相对路径。
- 命名空间配置、文件删除／重建、PHP payload 撤回会刷新匹配及受影响模型；位于默认模板根之外的命名空间目录仍消费 watcher。普通正文输入不会逐次重建全部模板映射。
