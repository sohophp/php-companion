# 魔术方法声明补全：当前类型去重

2026-10-02。本轮只修复当前类型已经直接声明的方法仍被建议的缺口。

## 实现

新增语义五项，修改前四失败、一反例通过。声明上下文携带当前最内层类型已经直接声明的方法名；按 PHP 方法名不区分大小写的身份规范化，排除当前正在编辑的方法。限定方法的 container 与声明范围，不跨类型、namespace 或匿名类作用域。

服务器的魔术方法候选使用该集合过滤。Class、Trait、Interface 与匿名类已验证；父类提供的方法继续可用于子类声明，不改变继承重写规则。正在编辑 __construct 本身仍有建议。此批没有增加签名模板或扩大枚举魔术方法支持。
