## 修改与选择依据

同一 242801 字节、1500 常量声明夹具的普通未保存连续编辑，原正式产物 PHP 7.2／8.5 各串行 100 轮，P95 为 200.65／154.04 ms，仍超过原 150 ms 预算。独立 CPU 采样定位解析遍历与 Tree-sitter 节点创建成本；用于定位的新 source map 已证明其服务器正文与被采样正式产物逐字节相同。采样延迟不作为普通性能资格。

文件末尾有未完成声明时，原解析器对每个有效节点也枚举全部子 token，检查缺失括号。本批只增加节点 `hasError` 条件：含错误的节点继续检查匿名缺失括号；具名错误、全部语义遍历、恢复规则与缓存保持。

两个独立原型各用 90 份已有 PHP 文件、22 份对抗输入和一份长编辑输入做对照：226 次完整／声明事实，加 339 次增量修改／还原，共 **565 次全部事实与错误范围一致**。包含匿名缺失符号、EOF、Unicode／CRLF、PHP／HTML、旧版 mixed／never 类名和 final Trait 恢复。
