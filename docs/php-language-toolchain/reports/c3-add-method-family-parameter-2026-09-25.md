`SoPHP: Add PHP Method Parameter with Preview` 现在可从方法声明生成统一计划。除上一轮的私有方法外，项目内可证明完整的公开或受保护方法家族会同时更新接口、父类和实现声明、已有 PHPDoc `@param`，以及解析到该家族的位置参数与 PHP 8 命名参数调用。不同实现原有参数名可以不同；新参数在各声明中使用同一个名字。单行 PHPDoc 会展开成多行，便于增加标签。编辑器先显示每个参与文件的差异，取消不改变源码，应用后可一次 Undo/Redo 恢复整组文件。
