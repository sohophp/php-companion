# C2：复用局部前缀语法检查

日期：2026-10-02。当前分支源码优化；未打包、提交、推送或更新 Profile。

## 修改

R22 的语法检查替代了原文正则误判，但同一位置会被局部类型和递归接收者查询重复扫描。原缓存只存在于一次 linearLocalValueType 调用内部。

现在在工作区内按文件 URI、作用域边界、body 起点及查询位置复用布尔结果。该检查只依赖语法，不依赖被查询变量；变量自身的引用参数／捕获、别名及实际调用参数证明仍单独执行。缓存最多 1,024 项，满时清空；不保存语法节点，不写入快照，不增加设置。风险节点分类和 4,096 节点扫描预算保持原样。

普通源码变化、删除文件、外部事实更新、工作区释放均清空缓存。补充恢复测试发现成功 restore/restoreDeclaration 也必须清空：同 URI、同长度的危险新快照曾沿用安全旧结果。新增负例先失败，补齐这两条成功恢复路径后通过；restoreSourceDeclaration 复用 restore，因此沿用失效处理。拒绝的快照不改变当前文件。
