# C3：预览式 Extract 应用后的多文件结果

日期：2026-09-26。预览式 Extract 原先在 `workspace.applyEdit` 返回 `false` 或抛错时直接报告失败，即使参与文件已经全部完成编辑也会误报。

现在以预览时的来源文本和目标文本计算每份参与文件的完整预期结果。应用后只有所有文件都匹配且计划实际产生变化，命令才报告成功；未应用和只修改部分文件仍报告失败。来源版本、磁盘摘要和预览标签检查继续在应用前执行。

验证：主扩展及宿主测试 TypeScript 编译、相关 ESLint 和 `git diff --check` 通过。VS Code 1.139.1 Linux x64 的完整 10 项 Open Source Pack C3 源码宿主退出码 0。多文件用例覆盖未应用、仅来源文件应用、全部应用后返回 `false`、全部应用后抛错；完整应用的两种场景各通过一次 Undo/Redo。该源码增量未打包 VSIX，真实 WSL Remote 与已安装候选仍待 C4。
