# D149：原生布尔字面量联合类型

## 修复与绑定

D148 原完整回归的 Filter 失败单独复现：三个合法的 `false|int`、`false|string`、`false|int|null` 返回被多报。原生标量转换只枚举一般标量目标，遗漏联合中明确允许的布尔字面量；弱模式还会把允许的布尔值错误投影为另一标量分支。

现先保留原生声明明确允许的 `false`／`true`，再做其它标量转换。一般 `bool` 输入按两种可能值投影，保留有效分支，不把 PHPDoc-only 合同伪装成原生声明。
