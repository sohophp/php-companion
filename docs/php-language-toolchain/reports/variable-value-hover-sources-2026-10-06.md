# D116 首次变量 Hover 的来源声明加载

日期：2026-10-06；基于产品 `087bd21a`、文档检查点 `687686f9`，继续原 C2 共享类型事实与 C1 按需查询。[结构化证据](variable-value-hover-sources-2026-10-06.json)绑定本次 bundle／源码摘要，保留原失败、当前协议、实际 UI 和性能数据。

## 缺口与实现

变量来自未打开的 Composer 类型属性／方法时，首次 Hover 缺少类型；先查询数组键补全后才恢复。问题也存在于普通变量、标量、实参、别名和嵌套捕获。旧产品原型矩阵 27 状态中 17 失败；正式四组版本／模式测试在旧产品均于首个普通数组用例失败，因此旧正式运行只执行了四次失败查询，不能记为完整 86 次对照。

将既有数组接收者的来源收集器提为共享内部方法，用精确变量引用／AST 位置取得所需声明，再复用现有按需 owner chain 加载。每次来源收集保留 128 节点、16 层及每变量 16 条先前赋值预算；声明加载与值证明分开，引用捕获、同名遮蔽、未知修改、unset 仍不能恢复旧值。使用已有未保存来源刷新和文档版本／取消保护，不增加公共协议、配置、Provider 或缓存格式。新增暂停点仅用于 testMode，验证加载后的异步边界。
