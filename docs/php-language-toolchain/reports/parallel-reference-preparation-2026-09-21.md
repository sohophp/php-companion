# 首次 References：有界并行准备候选语法

日期：2026-09-21。旧源码基线：`1fc856d`。

## 实现

按需方法 References 的项目扫描使用至多四个工作线程。冷缓存的文件先并行读取并解析：工作线程生成候选摘要以及完整或仅声明的 PHP 语法事实，主线程再按原文件路径顺序提交到同一个 SemanticWorkspace。PHPDoc、类型和跨文件继承关系仍由主线程结合已提交的文件计算。打开的缓冲区继续以编辑器内容为准；线程结果带有文件 URI 与源码哈希，不匹配时重新走原有解析路径。

工作线程只在需重建源码时启动，元数据匹配的持久缓存直接恢复。线程启动或解析失败时回退到原有同步解析，并在服务器错误输出中记录一次。并行预取保持每批 32 个文件的上限，取消仍在文件和批次边界检查。Parser 导出可传输的语法事实与控制流赋值位置，Semantic 接收这些事实并按原顺序完成语义更新；语法树仅在工作线程内创建和释放。

扩展构建新增 `candidateWorker.js`，VSIX 校验现强制检查该文件。
