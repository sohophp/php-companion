# D78 空初始化值的原生类型排序

## 实现

D77 恢复了空初始化位置，但 `bool $value = |`、带类型的属性／常量和枚举类型参数仍不能取得自己的原生类型。直接探针均没有兼容值；新增 40 项语义 baseline 为 30 失败／10 通过，负向无类型场景本来正确。

抽取并复用 D77 的临时 AST 恢复，类型查询和位置查询使用同一边界：131072 字符文档、160 字符前缀、256 层祖先，不修改源码、不发布恢复事实。使用单字符占位值，保持光标之前的类型位置，也避免扩展后的默认值超出原所有者的范围。恢复值只用于取得声明自身契约；普通赋值、无类型声明及其它语法上下文不能借用外围返回类型或相邻声明。

空初始化位置有已证明的兼容值时，服务器先显示这些值，再显示其它合法表达式种类；布尔关键字与值候选合并，避免同名重复，同时撤回通用关键字的预选。无类型时保持 D77 的原列表；有前缀的声明／表达式、PHP 版本过滤和 callable 插入继续复测。排序并不证明列表中每个低优先候选都符合具体声明类型。
