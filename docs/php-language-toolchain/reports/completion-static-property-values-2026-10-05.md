# D109 静态属性的数组读取补全

日期：2026-10-05；基于 `3f4aa7af`，继续原 C2 常用补全范围。

## 缺口与修改

原先普通属性已能提供数组形状键，`Config::$options['mo…']` 没有候选。现将具名类型、`self`、`parent` 的静态属性读取接入共享表达式类型事实，复用已有成员解析、访问权限和 PHPDoc 类型合同；局部变量接受该表达式后也保留形状。继承、Trait、命名空间别名、括号、嵌套读取、可选和共有 union 键沿既有规则处理。

真实 LSP 随后复现未打开 PSR-4 类仍缺少候选。服务器现在只沿当前数组读取的固定静态属性接收者加载声明及父类／Trait，复用现有八层加载上限与取消／文档版本检查。未闭合数组沿既有恢复实现查询接收者；没有改变 131072 字节、16 层定界符等恢复预算，没有增加设置或改变缓存格式。

动态类型／属性名、错误大小写、不可访问成员、实例属性的静态读取、unknown／宽泛／nullable 分支不提供确定键。非 final 类的 `static::$options` 可能由子类重新声明不同形状，保留不确定；final 类的固定合同可用。这里沿已有声明合同补全，不证明运行时属性已初始化或实际值总是符合 PHPDoc。
