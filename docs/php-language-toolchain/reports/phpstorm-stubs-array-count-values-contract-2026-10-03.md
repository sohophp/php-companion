# array_count_values：mixed 输入和计数返回

## 实现

来源为固定 phpstorm-stubs 修订 e4f5f6c3de39f3bab3e9f3fca4b8cdb8b061e681 的 standard/standard_9.php，结合六套 PHP 实测。宽静态重载保留原生 array 参数，不把 mixed 元素当作整个调用非法；返回 array<array-key,int>。整数元素的窄重载保留 array<int,int> 精度，未知原生 array 使用宽合同，避免多余联合类型。

保留 PHP 7 旧参数名／无原生返回标注、PHP 8 array 参数名／原生 array 返回。静态重载仍对应唯一运行时函数。不猜测具体键、计数数量或数组非空。
