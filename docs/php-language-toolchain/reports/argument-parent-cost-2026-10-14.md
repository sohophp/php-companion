# 实参检查中的父节点重复读取成本

2026-10-14。**成本观测已执行并通过，达到私有原型调查门槛；尚未实施缓存或证明性能收益。** 本批只测量正常 `incompatibleArguments` 同步检查中的原生父节点 getter，原 getter 的计算和返回值始终保留。

固定真实 Controller、PHP 8.5/onDemand、正常标准输入输出协议，两侧各四次编辑的完整诊断和可见补全摘要一致。补全比较排除内部 `data`，未执行 resolve。观测按 Tree 对象及原生节点 ID 区分读取，每次检查重新建表，最多 8192 个键；父节点 ID、范围和类型指纹的变化与上限截断分别记录。计时只包围原 getter 的计算，指纹和计数在计时之后，仍不能排除计时器及观察器带来的影响。

运行前固定原型调查门槛为四编辑重复成本中位数至少 50 ms，且结果、输入保持，无形状变化和截断。本次达到门槛，允许开始正确性原型调查。指纹一致和四次计时不能证明缓存等价，也不能推断可净节省 122.23 ms；本批不提供 P95 或复杂 Controller 原 500/150 ms 达标资格。

原型边界限定在一次同步实参检查的语法读取：按 Tree 与节点 ID 建表，结束释放，保留原递归和遍历预算；Tree 编辑、删除和源码更新需使对应条目失效。须核对返回对象共享、空父节点、可选访问、临时树及异常退出，随后验证完整原结果和预定 25 轮准入；未获准入即结束该假设。已有变量证明、签名缓存、范围裁剪等否定结论保持，不复测其等价方案。

独立终态核对已通过：3316 项产品和测试输入、66079 项固定项目输入及 25 项私有输入保持；控制构建八资产与正常 f607 逐字一致，两侧真实 getter 调用及四编辑的结果均已核实。驱动、全部阶段、两侧服务器和所属进程组已结束，独立缓存目录已删除；26 份原件与归档副本摘要核对通过。生产源码和运行包保持。
