# C2：独立构造赋值后的局部类型证明

日期：2026-10-01。源码增量；未打包、提交或更新 Profile。

## 问题与实现

局部变量赋值后，穿插 `$other = new Type()` 会让严格的局部值证明停止。成员补全可能使用另一条类型路径仍有结果，但参数诊断会降为 unknown。该限制在简写三元表达式实现之前已存在。

本轮把已有“字面量参数构造对象数组”的安全规则用于单个具名构造表达式。给另一个简单局部变量赋值、参数全部是字面量，且被查询变量没有可见引用或动态作用域风险时，可以继续保留原来的类型。构造表达式有语法错误时不采用该证明。

构造函数可执行任意代码，所以不能只凭“赋值给另一个变量”放行。全局作用域、引用参数、引用捕获、引用赋值、static/global、动态变量、include/eval/extract/parse_str 均排除；通过函数导入别名调用 extract/parse_str 也排除。参数包含变量、插值字符串或调用，动态类名，以及任意其它调用，继续保留 unknown。这些条件也保护原有构造对象数组路径。
