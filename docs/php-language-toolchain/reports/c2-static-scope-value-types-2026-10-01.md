## 修复与来源

静态方法里 `$value = null ?: new Repo(); observe($value, $options); $value->rea` 丢失成员补全，实例方法同一场景正常。局部逃逸检查从整个方法声明开始扫描，误把方法修饰符 static 当成共享局部变量风险。

现复用当前 CST 找到词法作用域 body，只从 body 开始检查动态作用域／共享绑定风险；找不到 body 则保留旧的 scope.start 回退。参数和捕获的引用信息仍独立检查，不通过删掉引用风险规则来恢复建议。真正的 static/global 局部语句及引用别名仍在 body 里，因此继续撤回证明。

修复先在[临时源码](c2-static-scope-snapshot-2026-10-01.md)验证。当前 R19–R20 全量 stdio 375/375、零跳过、1188.66 s，以及最终八项输入哈希通过后才应用，避免改变正在回归的输入。应用时断言语义主源文件与已测临时源文件逐字节相同；临时新测试原样加入当前包。
