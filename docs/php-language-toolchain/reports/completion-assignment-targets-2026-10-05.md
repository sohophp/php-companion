# D87 赋值目标与表达式接收者补全

日期：2026-10-05；基于 `fb23ef00`，同一开发分支上的 Core 源码里程碑。

## 实际缺口与改动

原有 `$holder->flag = |` 可以按属性类型排序，但 `$holder->child->flag`、`make()->flag`、`($holder)->flag` 与 `$holder->items[0]->flag` 等目标会退回名称顺序。现在由赋值 AST 确定当前值归属，再复用原有属性可写性、可见性、完整继承与类型证明。嵌套赋值使用自己的目标契约；未知目标不借用外层实参类型，内层调用、箭头函数与非透传运算保留各自边界。

共享成员接收者解析支持已证明的函数返回对象、括号对象和集合元素，在 `->` 后的初始列表、名称前缀、Hover 与跳转中使用同一事实。无关位置的未完成声明不再阻断已完整的接收者。私有、readonly、缺失、非法 nullsafe 写入、错误实参数量与标量接收者不产生可写类型契约；未知候选仍保留，不猜测动态目标。
