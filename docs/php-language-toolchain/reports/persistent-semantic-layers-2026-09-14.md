# 持久语义分层与派生依赖图验收

日期：2026-09-14。范围：P3 的引用候选持久化、类型派生依赖图、热启动恢复和单文件缓存损坏恢复。

## 实现

- `@php-companion/index` 新增 `DocumentDependencyGraph`。每个文档原子贡献有界节点与依赖边；同一逻辑节点可由多个文档贡献，删除其中一个文档不会误删剩余关系。
- `@php-companion/semantic` 快照升级为 schema 72，并把解析文件、引用候选键和类型依赖节点分层保存。恢复前重新验证派生层与解析文件一致；结构合法但内容陈旧的层也会被拒绝，随后只重新解析该文件。
- `SemanticWorkspace` 在更新、删除和恢复时同步替换反向依赖图。构造器或属性 hook 变化通过图传播到继承、接口和 Trait 依赖类型；图超限或不完整时清空派生缓存，避免保留过期结果。
- Language Server 持久缓存升级为 `semantic-v43-php-<version>`，旧 schema 不会被误恢复。

## 精准性证据

- index 单元测试覆盖原子拒绝、确定性快照、共享节点贡献和删除。
- semantic 回归从四个 schema 72 快照恢复 `Base → Middle → Child`，先证明 `Child` 的构造状态可用，再修改 `Base::__construct()`，确认传递失效后不再返回旧诊断。
- 快照回归分别篡改引用候选层、依赖层类型和依赖内容，均被拒绝。
- 10,000 文件基准篡改单个缓存条目的引用层后，9,999 个文件继续恢复，只重新解析 1 个文件；重建后声明仍唯一。
- 16 个组件共 622 项测试和根扩展 33 项测试通过；16 个组件 tarball 在隔离消费者中安装验证通过。
- 三份 VSIX 内容验证通过，主 VSIX 在 VS Code 1.137.0 隔离 Profile 的完整 Extension Host 回归退出码为 0。主 VSIX SHA-256 为 `ed89120d4f2acb37a2e93a079367ed84df633cc9d4081dbe2e82fcd14bde2241`。

## 10,000 文件 Linux x64 基准

命令：

```bash
pnpm benchmark:persistence -- 10000
```

结果：冷索引 16,977.41 ms；热启动 4,050.65 ms；热/冷比 0.2386。热启动解析 0 个文件并恢复全部 10,000 个快照。机器可读结果见 [persistent-index-10000-linux-x64-2026-09-14.json](persistent-index-10000-linux-x64-2026-09-14.json)。

## 边界

本增量完成引用候选和类型继承依赖的分层持久化。Callable 调用依赖、框架派生事实及更细的声明/方法体独立磁盘记录仍待实现，因此 P3 总项保持开放。该基准来自 Linux x64 本机，不代替 Windows、macOS、Remote 或真实项目长会话验收。

CI 已加入三平台 1,000 文件持久化基准并上传各自 JSON；只有对应提交的 CI 完整通过后，才能把它记为跨平台通过证据。
