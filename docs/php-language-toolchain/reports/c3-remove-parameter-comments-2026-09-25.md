# 删除方法参数时保留相邻注释

日期：2026-09-25。仅修改 SoPHP 源码和测试，未修改业务项目，未打包 VSIX。

## 问题与修复

删除方法参数时，原来的编辑范围延伸到下一个参数或实参的起点，可能连同保留项前面的注释一起删除。现在按参数列表和调用实参列表中的实际逗号计算删除范围，并跳过字符串及注释中的逗号。公共方法家族和私有方法的删除参数操作共用此规则；无注释的紧凑写法仍保留正常间距。

## 验证

- 先用注释场景复现声明和调用处的注释丢失，再修复；语义测试 369/369 通过，覆盖删除首尾参数、注释中的逗号、紧凑写法和 PHP 解析结果。
- 语义包 TypeScript 检查、改动文件 ESLint、`git diff --check` 通过。
- 独立 Linux VS Code 扩展宿主 `pnpm test:extension:c3` 退出码 0；新增场景通过预览取消、应用、一次 Undo/Redo，保留声明与调用处的注释。日志：`/tmp/sophp-c3-commented-remove-host-fixed-20260925.log`。

这次验证是源码扩展宿主，不代表已安装 VSIX、完整 Open Source Pack、WSL Remote 或人工持续使用。类型生成新文件的一次 Redo 仍未恢复文件，C3 尚未收口。
