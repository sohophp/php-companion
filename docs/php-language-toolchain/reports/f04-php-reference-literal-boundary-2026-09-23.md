# F04 PHP References 的代码与文本边界

日期：2026-09-23。本轮使用独立 PHP 输入验证通用语义核心：类方法调用和全局函数调用的样式同时出现在可执行代码、单引号字符串与注释中。修复前，References 把字符串和注释中的文本也返回为方法/函数引用；函数查询在 `includeDeclaration=false` 时还把声明本身返回。

References 的成员与函数候选遍历现在先检查解析器给出的字符串和注释范围。候选若完全位于这些范围内，就不作为代码引用；函数声明在 `includeDeclaration=false` 时也不会通过调用扫描重新加入。正常调用继续按原有语义解析，`includeDeclaration=true` 仍保留声明。

语义包的独立输入同时断言两种声明模式、真实调用的精确范围及字符串/注释反例；真实 Language Server stdio 的 `textDocument/references` 对方法和函数分别返回唯一实际调用位置。语义包 310 项、类型检查、相关 ESLint 及定向 stdio 用例通过。

语言服务器全套回归本轮为 288 通过、6 失败、1 跳过：5 项等待响应或测试超时，另 1 项 Symfony 静态路由补全结果为空。单独复跑其中 XML 服务刷新与静态路由两项仍失败，因此不能宣称全套通过；这些失败尚未归因。本报告只证明所列通用 PHP References 场景，不依赖项目专用 Provider。最终 F04 仍需完成其它导航场景与编辑器矩阵。
