# C3 测试类生成：选择后目录消失

日期：2026-09-25。范围仅为 SoPHP Core 与独立隔离宿主，未修改业务项目或打包 VSIX。

在没有 Composer `autoload-dev` 映射的项目中，测试类生成会让用户选择测试目录。如果目录在选中后、预览前被外部操作删除，原实现的 `workspace.fs.stat()` 异常会使命令直接抛错。现在它将目录不存在或不可访问视为无效目标，给出中英文提示并返回 `false`，不会打开预览或创建目标文件。

隔离 C3 宿主增加了目录选择回调中删除目标目录的场景，验证命令结果、预览状态和文件不存在；之后重建目录，正常测试类生成继续通过。`pnpm test:extension:c3` 退出码 0（`/tmp/sophp-c3-deleted-test-directory-20260925.log`）；相关 ESLint 和 `git diff --check` 也通过。根扩展构建与测试 TypeScript 编译由 C3 命令完成。

此项收口的是生成前目录变化的失败反馈。新文件创建后的一次标准 Redo 仍未恢复文件，C3 该门槛继续开放。
