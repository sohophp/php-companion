# References：限制局部语法查找范围

日期：2026-09-21。源码基线：`7fabeb7`。

## 热点与改动

此前 CPU 采样中，`callableVariableResultType` 的 431 个样本有 424 个落在 `firstLocalSyntax`；该查找虽检查目标源码范围，却仍遍历整份文件的其他子树。

为 `firstLocalSyntax` 增加可选源码范围：跳过完全不相交的子树，保持范围内的先序匹配、遍历预算和保守失败行为。局部可调用变量结果推断、生成器声明查找传入已有精确范围。另外，仅在函数声明源码出现不区分大小写的 `yield` 单词时继续生成器分析；注释或字符串中的同名单词仍走原解析，不能因此误认生成器。

新增引用/定义回归包含目标调用前后同名的无关局部变量和中文源码；已有生成器推断测试改用大写 `YIELD` 覆盖关键字大小写。

## 实测

同机串行运行独立 Language Server 进程，查询 Winstar `AdminPasswordChangeGuard.php` 最后一个 `get`。冷查询使用空持久缓存；每次先 Definition 后 References。以下为单次观测，不是 P95。
