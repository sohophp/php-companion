## 修复依据与范围

`XMLReader::XML` 和 `open` 支持两种原生调用：实例调用返回 `bool`，静态调用返回 `XMLReader|false`。PHP 8.0 起声明为 static，仍能通过实例调用；PHP 7 静态调用有弃用警告。官方 [XML 文档](https://www.php.net/manual/en/xmlreader.xml.php)和 [open 文档](https://www.php.net/manual/en/xmlreader.open.php)均明确区分这些契约。

六个真实 CLI（7.2.34、7.4.33、8.1.34、8.2.32、8.4.23、8.5.9）分别运行两个 API、两种调用：实例结果均为 boolean true，静态结果均为 XMLReader，输入未变化。XML 使用内存文本，open 使用 `data://text/plain,<root/>`，没有网络或磁盘读取。PHP 7 的弃用警告如实保留；未实际运行缺少的 7.3／8.0／8.3 CLI。

语义层在真实继承与 override 合并完成后，给这两个内建方法提供访问形式对应的契约。原始声明、修饰符检查、参数、定义位置保持；用户同名类型与覆盖方法不获得伪造别名，移除扩展声明后不凭空生成成员。

原先实例调用被误当成未知调用，连带丢失后续静态 factory 所用输入类型，最终 false guard 后的 `localName` 跳转为空。本次恢复实例调用和静态返回对象的成员推断。旧测试 `$legacyReader->XML(...)` 的返回类型从 `XMLReader|false` **纠正为 `bool`**，有六 CLI 与官方契约依据；保留调用、参数及原来失败的属性跳转断言。
