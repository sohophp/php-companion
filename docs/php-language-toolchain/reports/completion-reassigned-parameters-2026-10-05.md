# D82 参数重新赋值后的补全事实

## 已复现的错误

在 `run(int $offerA, string $offerZ)` 内把 `$offerA` 改为字符串、`$offerZ` 改为整数后，字符串实参位置仍把 `$offerZ` 排第一，但候选说明已经显示 `$offerA: string`、`$offerZ: int`。保留及临时语法树均复现。修正刷新语料的替换位置后，前一产品的 20 个独立回归用例全部失败，包含函数、方法、闭包、PHPDoc、返回、位置／命名实参和 unknown 赋值。

参数声明约束函数入口，不约束之后的局部变量重新赋值。当前语义入口在存在同作用域、光标前已完成的赋值时，使用既有的当前局部值证明；不能证明则保留 unknown，不退回旧声明类型。候选说明也走此入口，去除重复的赋值分支。没有修改参数声明、签名契约、类型猜测、配置或缓存。
