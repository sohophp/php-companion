# C3 Extract Method：完整分支的输出列表

日期：2026-10-02。继续 F08 的多语句／多输出支持，沿用已有完整分支的安全证明。

## 实现

原实现限定分支各有一至两条赋值，三个必有输出无法提取。新实现将完整分支的输出作为列表处理，每个分支允许 2–32 个独立新局部输出；单输出及已有部分分支规则保持各自支持域。

- 按第一个分支的输出顺序检查所有分支，数量、名称顺序和位置类型必须一致，最终 else 必须存在。
- 检查整个列表的名称唯一性，防止第三项以后的重复输出；不放行输出间依赖、引用赋值、已有局部、参数或超全局变量。
- 仍要求每个输出在选区后使用，条件只使用已有原生 bool 参数证明；输出类型未知、void／never、不完整语法或注释等既有拒绝边界保留。
- 复用现有返回数组、调用处解构及 array-shape PHPDoc，不另建数据流分析或引入配置。每分支超过 32 项明确不提供动作。
