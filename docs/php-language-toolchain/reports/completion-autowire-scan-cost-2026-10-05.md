# D75 普通 PHP 补全中的按需 Autowire 扫描

日期：2026-10-05；基于 `fec034ee`。本批只改变 Symfony Provider 的服务字符串识别入口，Core 的解析器与语义源码保持。

## 本轮决定

100 轮当前输入的独立 CPU 采样定位到：普通代码补全也调用 `symfonyAutowireServiceIdAt`，在没有可能匹配属性时仍遮罩整份文件。现在先使用**原有正则**查找首个可能的服务字符串；没有匹配时直接返回空结果。存在匹配时继续原有命名空间、别名、注释／字符串排除及完整循环，保留首个匹配和后续真实属性。没有新增配置或缓存，不降低 Provider 的证明条件。

独立等价检查覆盖 70 份源码、10000 个光标位置，完整引用及定位结果均相同。新增固定回归覆盖假注释、无关属性在真实属性前出现、Unicode 偏移以及两个真实服务的完整范围。

另一个主遍历原型在 166 份完整事实、2988 份诊断／符号对照中保持一致，但普通对照的 P95 未改善，CPU 收益也不足以证明采用它的价值，**没有写入产品**。该原型和失败的测量保留在结构化记录，不继续尝试同一遍历变体。
