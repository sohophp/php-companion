## 修改与边界

- 沿用现有 PHPDoc AST，只绑定类型名称；按 Trait 原声明的命名空间和 import 解析类名。消费类另用于 `self`／`parent`，不把源文件的名字解释为消费类中的同名类。
- 保留数组形状键、字符串字面量、回调参数名、分组及条件类型中的变量。覆盖名称／别名／绝对名、可空、数组、list、形状、class-string 和回调；三种缓存恢复后变更 import 能撤回旧事实。
- 构造方法模板保持符号名称，边界按源声明绑定。诊断及实参排序复用实际模板；同名消费类 `T` 不替代模板。不支持的 Trait 类模板使用绑定、局部类型别名、错误或超预算文档撤回精化，原生合同仍保留。没有声称完成所有 Trait 泛型或 PHPStan 类型 DSL。
- 真实协议暴露匿名函数原生参数／返回类型误用文件默认命名空间的问题；修正为类型声明实际位置，包含箭头函数和多个命名空间的反例。
- 完成嵌套调用的 `)` 后，签名帮助回到外层；最外层关闭后不保留旧提示。已解析参数范围采用半开区间，未闭合输入继续使用原有恢复路径。普通函数、实例／静态方法、构造和包含括号的字符串均有控制。

新增 28 项 PHPDoc／回调检查及 22 项签名边界检查，共 50 项。复用既有解析器，无新依赖、设置或持久化字段，语义缓存仍为 84。
