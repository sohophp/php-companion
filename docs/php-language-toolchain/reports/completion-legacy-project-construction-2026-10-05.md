# D106 普通项目的 PHP 7 旧式构造函数

日期：2026-10-05；基于 `14fd8b5a`，延续 C1–C4 的构造补全与版本一致性。本批是本地源码里程碑。

## 已修复

原产品在 PHP 7.2 项目中，对 `class C { public function C(int $value) {} } new C()` 返回空签名，也不报告缺少实参；原正式 bundle 的真实 stdio 固定回归已复现失败。

语义工作区现在接收语言服务器已选定的 root PHP 版本，普通项目文件也能识别旧式构造；不增加用户设置，不从目录名猜版本。无 root 文档沿现有 fallback，同一服务器的不同项目分别绑定。查询 fork 保留版本；版本变化撤回旧签名、兼容变量排序、诊断与派生缓存，并使旧修订证明失效。

按照 [PHP 官方构造规则](https://www.php.net/manual/en/language.oop5.decon.php)，PHP 7 全局类的同名方法可以构造对象，PHP 8 与命名空间内的类同名方法保持普通方法。直接声明、大小写、父子类优先级、Trait／嵌套／别名及可见性共用现有构造绑定。真实 PHP 7 会拒绝的 Trait 新旧构造冲突及静态旧式构造不生成确定签名；未知或不完整 Trait 来源保持保守。

快照仍只保存现有源码／声明／实现事实，不保存版本相关的构造选择，因此不改变 87／5 结构合同；恢复后按当前工作区版本查询。未提供版本的独立语义调用保持原保守行为，受审计内建 URI 的 PHP 7 权威继续保留。原魔术构造函数参数重构限制不变。
