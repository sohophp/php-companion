## 预检问题与修正

最初基准未传配套 WASM 路径，两种模式在 initialize 报 ENOENT；第一次输出又因空样本统计抛错而缺少 JSON。随后保留失败日志，并让无样本统计输出 `null` 和各轮错误，确认真实错误为基准启动参数缺失。传入与编辑器相同的解析器路径后，两模式预检通过，再增加精确签名／替换文本断言并冻结脚本进行正式矩阵。ESLint 与 Node 语法检查通过。没有将基准自身错误算作产品缺陷，也没有修改产品绕过断言。

正式矩阵的脚本、根 bundle 和两 WASM 摘要在前后相同；正式结果未重跑。预检属于不同脚本版本，不纳入 60 轮正式样本，但原失败完整保留。
