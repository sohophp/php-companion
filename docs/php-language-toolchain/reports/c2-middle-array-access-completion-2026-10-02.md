# R41 文件中间未闭合的数组读取补全

日期：2026-10-02。当前分支已应用；接续 R39 的已知数组读取与 R40 的实际 Core／Symfony 完整 C3 验证。

## 缺口与修改

原来恢复只接受光标位于文件末尾。真实中间输入 `$options['mo|]; echo 'done';`、未闭合下标后有下一语句或闭合块，以及读取位于实参时，四个只读基线场景全部没有 `mode` 候选。

现在在独立查询副本中按光标后的实际边界补齐当前引号／下标，保留完整后续源码。已有 `]` 直接复用；分号、实参逗号、调用闭合括号、块闭合或下一行语句分别验证。完整恢复源码必须通过语法检查；无法恢复或有其它语法错误时不猜测。原文件事实与 revision 保持，返回编辑范围只覆盖光标前未完成键，不消费下一行、括号或后续语句。

第一次定向测试发现单引号被后续 echo 的引号闭合，导致原字符串范围过滤漏掉当前开头；修正为读取光标前字面量前缀，并验证恢复后的整个源码。保持 128 KiB 文件／16 层分隔符和路径预算，不更改字符串转义语义、未知调用或动态绑定的证明规则。候选仍只插入键字符串，实际编辑中的其它未闭合括号由后续输入完成，恢复用分隔符不写入文件。
