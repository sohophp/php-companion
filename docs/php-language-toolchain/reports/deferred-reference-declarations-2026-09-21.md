# 首次 References：声明提取与延迟方法体

日期：2026-09-21。优化前源码基线：`0db6e4e`。

## 实现与准确性边界

Parser 新增 `parseDeclarations()`，只提取完整声明、import 和注释范围，包含嵌套函数、匿名类及错误恢复中的声明。Semantic 新增 `updateDeclarations()`：声明立即参与继承和成员归属判断，需要实现事实时才从保留源码补齐；查询已有的语法树继续复用并按原生命周期释放。编辑、移除和快照恢复会清理旧状态；导出完整语义快照前必须补齐方法体。

Language Server 仅在方法 References 的按需扫描中启用此路径。原有保守子串候选范围保持不变；完整源码摘要能够证明没有目标标识符的关闭文件只建立声明，仍可为真正的引用文件提供父类、Trait 和属性类型。摘要不完整、打开缓冲区及其他查询继续完整解析。实现引用的候选选择会包含尚未加载方法体的文件，避免把缺失事实当作没有引用。

声明使用独立缓存载荷保存，校验 URI、源码 hash、完整载荷 checksum 及语义声明结构，复用有界压缩和解压；损坏或不匹配时回退源码。旧的完整缓存仍可使用，声明载荷不会冒充完整实现快照。
