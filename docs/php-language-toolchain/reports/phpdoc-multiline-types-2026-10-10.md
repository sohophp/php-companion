# 多行 PHPDoc 类型与语义传播

多行类型现已接入正常 PHPDoc、语义核心和生产语言服务器。支持嵌套 array/object shape、泛型、Callable、条件类型、模板约束和 `@method` 参数；类型、变量名和说明继续分开保存。LF、CRLF、CR 注释行装饰按原宽度遮蔽，嵌套节点及 magic method 参数仍使用原始 UTF-16 范围。

后续物理标签行（包含未知标签）结束当前标签体，未完成 return shape 不会吞掉相邻标签或发布局部对象成员。解析出错的标签保留局部 AST/错误并标记 `invalid: true`；语义查询撤销旧成员事实。继承构造器类型绑定去除行装饰，移动成员的名称绑定保留原始装饰、字段键和字符串字面量，普通独立类型中的 wildcard 不会被误当成注释。

语义快照由89升到90，源码声明快照由7升到8；持久缓存消费者同步拒绝旧快照，Doctrine facts 和外层缓存版本保持各自合同。
