# 容器 Provider 物理取消与正常验证

2026-10-09。正常源码和构建已接入可选 `AbortSignal`。最后一个共享容器调用者取消、输入/请求/索引代次过期或服务器关闭时，终止所属的直接 Provider 进程；仍有调用者时保留共享进程。中断的旧准备不会清除新事实或提交旧快照。

主机先发 SIGTERM，25 ms 后仍存活则发 SIGKILL，等待进程关闭后返回失败。提前取消有效请求时不启动进程；已经返回的成功响应保持。超时、stdout 超限及 stdin 失败也使用回收路径。

正常 Linux 真实主机中，直接取消退出为 5.97 ms，忽略 SIGTERM 的进程为 29.52 ms；PHP 7.2/8.5 目标配置中，全部调用者取消为 24.87/30.01 ms，shutdown 为 8.75/8.06 ms，均在原 100 ms 门槛内。保留两个仍有调用者的进程存活正例、取消后重试、最新快照和原完整断言。26 个正常语言服务器及全部观测到的 Provider 均已退出。

主机/服务器包构建、根严格类型、全仓 Lint、生产 bundle 全部通过；正常八资产与隔离候选逐字相同。原 20 项协议与主机 10 项保持，新增 12 项分别验证物理资源和共享调用者所有权。

隔离验证器的参数化案例计数和带引号标题匹配曾失败，原记录保留。原主机/协议失败对照和已通过候选主机按实际源码、资产、依赖和结果身份复用；仅执行尚未运行的候选协议。补充默认 reporter 保存真实退出观察，未改变原断言或预算。

直接进程是本轮终止范围；其它三类 Provider 调用尚未传入取消信号，后代进程和长任务准备的完整取消预算继续。新构建完整 LSP/编辑器/12 扩展组合、全部性能/平台/长期/真人及原完整目标尚待后续资格，不继承[接入前正常构建](shared-container-normal-qualification-2026-10-09.md)的结果。用户 Profile 未更新，没有打包、提交、推送或发布。
