# C2 补全候选弃用标记

补全现复用声明的弃用语义，为已证明弃用的候选输出标准 LSP `CompletionItem.tags = [Deprecated]` 与兼容字段 `deprecated = true`。覆盖函数、类型、方法、PHPDoc 属性、全局常量、类常量和枚举 case 的普通候选，以及函数／常量导入候选。

候选按原始声明位置读取元数据，保持现有候选排序和插入文本。PHPDoc 的 `@deprecated` 对所有支持版本生效；`Deprecated` 属性按 PHP 8.4／8.5 合法目标过滤，不把类上无效的属性当作弃用标记。成员重写以子类声明为准，不继承父类方法标记；未保存的声明更改立即反映到候选。没有可证明声明身份的合成候选保持现状。

- 真实 stdio LSP 三项通过。两项验证 PHP 7.2／8.5 的 Mcrypt 候选携带弃用标签；另一项覆盖函数、类型、Trait、方法、属性、常量和导入，并验证正常方法、子类重写及删除 `@deprecated` 后无标记。
