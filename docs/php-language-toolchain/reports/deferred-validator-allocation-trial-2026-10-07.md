# D305–D307：延迟实现验证器的私有分配对照

日期：2026-10-07。正常 Core `079ffa1b`／semantic `1b7ec969` 保持。**只有私有副本试验，尚未修改产品源码或取得正常构建资格**。详见[机器报告](deferred-validator-allocation-trial-2026-10-07.json)。

## 改动及前提

基于 D303–D304 的声明恢复分配栈，只在私有 compiled 副本中把验证器的 records 包装及事实／offset 的迭代改为按索引读取。所有事实类型、范围所有权、顺序、Callable 身份／kind／边界、offset 唯一性等判断原样保留；没有跳过校验，没有改变存储格式或加生产 GC。

首次 D305 在加载私有副本时因 `@php-companion/index` 解析不到而退出 1（0.19 秒），试验未执行。原失败／冻结输入保留。为两份私有副本指向原 semantic workspace 的既有 node_modules 后，D306 独立运行通过；原源码／构建未变，不把首次准备失败称为产品行为失败。

## 行为等价

90 份现有 PHP fixture，加原规模生成器的典型文件以及嵌套 Callable、property hook、Trait alias、混合未完成输入，共 95 份；原验证器全部接受。逐份比较原版与候选，含缺失事实数组、非法 offset、Callable 身份／kind／范围／scope 与重复记录，**2053 次结果对照一致，其中 1958 次明确损坏拒绝**。每次检查输入快照未变。

本试验不替代全语义／LSP 或所有未知输入证明；源码接入前还需补强范围所有权和排序的针对性永久反例。D306 3.32 秒退出 0；4300 冻结输入、两仓及正常组件／Node／实际 CLI 均保持，改变 0 项。

## 私有采样

只对同一典型规模文件、每次 20000 次验证，按 ABBA 顺序做四次分配采样。平均间隔 8192 字节，包含已由 Major／Minor GC 回收对象，不主动 GC。

| 次序／实现 | 验证次数 | 累计采样 selfSize | 插桩耗时 |
| --- | ---: | ---: | ---: |
| 1／baseline | 20000 | 187.62 MiB | 258.48 ms |
| 2／candidate | 20000 | 125.29 MiB | 206.82 ms |
| 3／candidate | 20000 | 129.19 MiB | 205.81 ms |
| 4／baseline | 20000 | 180.11 MiB | 200.47 ms |

各两轮合并，候选的累计统计分配归属比基线低约 **30.80%**，支持进入最小源码试验；这不是精确字节节省，也不是缓存恢复或 RSS 降幅。末轮基线耗时比两轮候选都短，**不宣称耗时改善**。单一典型输入的私有采样不代表普通编辑、完整缓存序列或其它场景。
