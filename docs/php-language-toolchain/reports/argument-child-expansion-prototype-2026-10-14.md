私有原型仅在一次同步 `incompatibleArguments` 内缓存子节点字段描述，以 Tree 对象和节点 ID 为键，额外匹配父节点索引、坐标及上下文字段，上限 8192。命中仍用原 `Node` 构造器创建独立数组、节点及坐标对象，保留同一包装对象的原数组缓存行为。未命中保留原 getter 计算；Tree 编辑、删除和 Node 编辑清除受影响树的内外层上下文，退出及异常用 `finally` 恢复外层作用域。没有跨检查、异步或编辑复用。

**已执行并通过**：候选类型检查；9 项实际原生树边界，包括数组/节点/坐标可变性、空数组、复制树共享节点 ID、偏移坐标、Tree/Node 编辑、内外层删除失效、上限、异常恢复；480 状态跨文件签名变化、删除及声明恢复结果对照。对实际发出的候选 JavaScript 另行复核同一 480 状态，两次均观察到 96 次实际私有 SDK 作用域调用，避免原型未加载造成误判。两侧各 24145 项完整语义、58 项定向协议及 36 项版本定向检查通过，用例身份、数量和状态一致；532 项未选中另列。

语义源码、实际发出的候选 JavaScript、私有 SDK 在完整语义与运行包中的加载摘要均核实。源码转换反向核对可逐字恢复原第三方文件，确认原 Node 构造器和 getter 未命中计算保留。候选只在原语义源码末尾追加作用域包装，原业务方法体保持。

**已执行但失败并保留**：边界检查初次错误地保留预期坐标对象引用，测试自身修改了预期快照；第二次错误地假定复制树根节点 ID 必然相同，改用实际共享 ID 的子节点核对树隔离。辅助源码核对初次忽略末尾源码映射注释的位置，错误地要求候选 JavaScript 包含完整原文件为前缀，随后排除该末尾注释核对原方法体。三次失败的脚本及记录保留，原型没有因这些测试前提修正而改变。
