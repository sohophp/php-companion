## 实现

- `@param-out`、`@phpstan-param-out`、`@psalm-param-out` 与输入 `@param` 分开，支持现有 stubs 的同一行多个标签；完整长标签边界及引号类型范围保持。`ParsedParameter.outputType` 是独立声明事实，变化会撤回旧推断，参数 Rename 包含输出注解。
- 调用返回后建立输出值，复用现有局部值及分支、循环、try/catch 推断；覆盖新变量、调用者参数、标量、nullable、数组形状、class-string、成员及继承调用。引用别名、全局变量和引用捕获在后续未知调用、别名写入、其它共享写入后失效。
- 类／继承／Trait／嵌套 Trait 泛型采用已有签名绑定，方法模板优先于同名类模板；Trait 方法别名按原声明身份查输出契约和引用效果。`self`／`static` 在有效调用上下文解析，不借用同名调用方类型。
- 无赋值语句的引用生产调用也进入有界来源依赖。输出类尚未加载时先读取声明中的类名作为加载依赖，加载后再证明变量类型；依赖不会让单边分支或危险写入获得补全。复用服务器现有读取、取消及文档版本保护，没有执行项目 PHP 来猜类型。
