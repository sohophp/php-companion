## 改动

- 合法 PHP 的完整解析使用 Tree-sitter 原生后代筛选，只把产生语义事实的命名节点交给 JavaScript visitor，保留遍历顺序和真实父节点。错误文件仍执行原有完整恢复遍历；新语义节点种类需要同步维护筛选列表。
- 原生筛选也可能返回同名的匿名关键字，例如类型 `string`。显式检查 `isNamed`，避免把类型关键字误当作字符串范围；此次全项目对照发现了该问题，已补回归用例后重新审计。
- 候选摘要使用默认 Unicode 大小写映射替代每个标识符上的 `en-US` locale 转换；查询名在每次查找中只归一化一次。Unicode 特殊大小写与完整/子串/具名参数匹配均有回归覆盖，缓存格式不变。
- 推断类型的声明存在性判断使用现有声明索引，避免每次汇总全工作区声明。既有名称选择优先级保持一致，新增、移除、命名空间变化和声明缓存恢复均重新参与查询。
